01

公主与塔

0 / 3 步骤+

恢复森林铁路地图。

攻略路线与谜题解法

  1. 01

    完成工程师之旅并帮助塞尔达在不被发现的情况下离开城堡。引导她在安全位置之间移动，同时林克分散警卫的注意力。

  2. 02

    在灵魂之塔中，收集三颗光之泪来增强剑的力量。从后面攻击幻影，以便塞尔达可以占有它。

  3. 03

    当林克处理开关时，使用塞尔达的盔甲穿越危险或分散其他幻影的注意力。出发前收集森林铁路地图。

02

恢复森林王国

0 / 3 步骤+

完成第一首洛科莫二重唱。

攻略路线与谜题解法

  1. 01

    沿着树木的指示穿过失落的森林，包括线索给出的最后一个例外。在二重奏之前到达盖奇并练习长笛序列。

  2. 02

    在森林神殿内，使用旋风移动钥匙、清除毒雾并将爆炸的敌人击向障碍物。

  3. 03

    吹散保护斯塔诺克斯后方的云层并攻击它。在飞行阶段，将具有爆炸性的敌人吹向 Boss，将其击落。

03

雪地轨道

0 / 3 步骤+

恢复第二个区域。

攻略路线与谜题解法

  1. 01

    完成下一个塔楼部分并获得雪地铁路地图。使用阿努基和费鲁斯的线索找到穿越暴风雪的路线。

  2. 02

    斯蒂姆二重唱后，进入雪殿并收集回旋镖。在携带该元素的预期目标之前画一条穿过火或冰的路径。

  3. 03

    用相反的元素击中弗拉兹。当原来的火把被摧毁时，使用他攻击留下的火和冰作为你新的元素来源。

04

一条海底铁路

0 / 3 步骤+

打开海洋神殿。

攻略路线与谜题解法

  1. 01

    恢复海洋铁路图，安排断桥的修复，并将卡本从帕普奇亚带回来。他的二重唱恢复了通往水下路线的轨迹。

  2. 02

    在海洋神殿中，获得鞭子并将其用于杆子、把手和开关。在拉随机序列之前阅读剑柄线索。

  3. 03

    从 Phytops 的卷须上拔出一根刺，扔到受保护的眼睛上。清除覆盖物，击晕眼睛并用剑攻击。

05

戈隆与火神庙

0 / 3 步骤+

恢复最终境界的轨迹。

攻略路线与谜题解法

  1. 01

    从雪地运送巨型冰块以疏通戈隆定居点。规划火车路线以减少融化并避免不必要的损坏。

  2. 02

    完成恩布罗斯的二重唱并收集进入神殿的钥匙。在火神庙内，使用弓和矿车激活远处的目标。

  3. 03

    射击克拉格玛发光的身体点来改变竞技场的路线。乘坐矿车向上射击眼睛，然后在 Boss 倒下时进行攻击。

06

塔顶

0 / 3 步骤+

找到被夺走的塞尔达身体。

攻略路线与谜题解法

  1. 01

    返回精神之塔并使用不同的幻影形态来应对特定的障碍。受保护或困难的路线可能需要塞尔达（Zelda）带领。

  2. 02

    在伯恩的战斗中，将塞尔达放在她可以抓住他伸出的爪子的地方。当她按住林克时，将林克移动到攻击位置。

  3. 03

    在塔楼序列之后，跟随 Anjean 的新线索。塔楼表面上的修复并没有结束故事。

07

光之弓

0 / 3 步骤+

为黑暗领域做好准备。

攻略路线与谜题解法

  1. 01

    找到雷尔，完成二重唱并通过铁路试炼。进入沙神庙并取回沙魔杖。

  2. 02

    在林克和重物下方抬起沙子，以到达壁架或移动障碍物。临时沙平台会倒塌，因此在创建它们之前请准备好下一步行动。

  3. 03

    用凸起的沙子抓住斯凯尔德里奇滚动的巨石，然后将它们发射到它的装甲中。战斗后到达暴露的弱点并收集光之弓。

08

最后一次攀登

0 / 3 步骤+

找到光之指南针。

攻略路线与谜题解法

  1. 01

    带着光之弓返回灵魂之塔。操作光敏目标时蓄力射击。

  2. 02

    使用火炬幻影照亮黑暗路线，使用扭曲幻影到达适当的目标，使用清障车幻影打破沉重的障碍。

  3. 03

    协调塞尔达和林克在最后房间的开关的位置。带着光之罗盘，沿着新发现的轨迹前往黑暗领域。

09

黑暗领域

0 / 3 步骤+

击败马拉杜斯。

攻略路线与谜题解法

  1. 01

    收集光之泪，让列车暂时无敌，撞击装甲列车。摧毁恶魔列车的武器，同时切换轨道以避免攻击。

  2. 02

    引导塞尔达经过科尔，这样她就可以抑制马拉杜斯，然后射出光之弓。在下一阶段保护她并完成长笛二重奏。

  3. 03

    转动马拉杜斯，以便塞尔达可以射击他的背部。在他倒下时击中额珠，完成最后的组合攻击。

邮票和完整的铁路

  1. 01

    拿着 Niko 的邮票簿，在到达每个车站时盖上印章。在奖励里程碑处返回给他，而不是等到最后一站。

  2. 02

    重新审视客运和货运请求的解决方案。安全运送货物以获得原力宝石，以恢复可选的轨道部分。

  3. 03

    使用完整的铁路地图检查孤立的分支、兔子和支线目的地。主线故事中修复的轨道并不包括所有可选的铁路。

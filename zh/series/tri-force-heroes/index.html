01

兀兰

0 / 3 步骤+

学会在三个高度工作。

攻略路线与谜题解法

  1. 01

    Deku Forest 和 Buzz Blob Cave：学习将队友扔到更高的壁架上，并从图腾上射击升高的目标。将所需的项目用户保留在顶部。

  2. 02

    莫布林基地：将英雄分开进行切换，并在每次穿越后重建图腾。将三人全部带到 Triforce 网关。

  3. 03

    森林神庙：射箭穿过火焰来点燃火把。轰炸玛戈玛的开口，将一名英雄扔到身上并击中眼睛；根据需要增加图腾的高度。

02

河滨

0 / 3 步骤+

将水柱与握把结合起来。

攻略路线与谜题解法

  1. 01

    用水杖创造水柱作为临时落脚点，完成河畔区域的前两个关卡。

  2. 02

    过渡海湾：将英雄放在不同的开关上，打开路线并以正确的顺序重新组合他们。避免搁浅唯一可以到达剩余玩家的英雄。

  3. 03

    水神庙：使用抓握射击穿过目标并救回队友。将阿古斯较小的眼睛拉开，然后使用高大的抓握图腾到达它的中央眼睛。

03

火山

0 / 3 步骤+

交叉移动平台和矿车轨道。

攻略路线与谜题解法

  1. 01

    炽热轨迹：使用狂风罐将队友送过缺口，并使用回旋镖来找回留下的英雄。投掷前确认安全着陆。

  2. 02

    辛诺克斯矿井和火焰巢穴：定时攻击和移动车的切换。返回敌人的炸弹，同时让他们远离其他英雄。

  3. 03

    火神殿：协调boss之前的定时切换。攻击摩尔多姆的尾巴，然后随着其弱点的上升而增加弓箭使用者的高度。

04

冰之洞窟

0 / 3 步骤+

控制湿滑的地形。

攻略路线与谜题解法

  1. 01

    冰冻高原和雪球峡谷：使用火焰手套融化障碍并点燃火把。在穿越之前让滚动的雪球堵住冰冷的通风口。

  2. 02

    银神殿和冰神殿：在弹簧平台上使用锤子并分阶段移动英雄。转辙操作员可能需要最后加入移动平台。

  3. 03

    锤击暴风雪的头部直至其外壳破裂，然后使用剑攻击暴露的宝石。避免紧紧跟随其身体，以免转弯时抓住每个英雄。

05

堡垒

0 / 3 步骤+

到达女士的巢穴。

攻略路线与谜题解法

  1. 01

    密封之门：让一名英雄处于必要的控制之下，而其他英雄则乘坐电梯。仅在路线保持开放后重聚。

  2. 02

    炸弹储存和训练场：将炸弹重定向到目标并使用正确的图腾高度进行切换。当爆炸物起作用时散开。

  3. 03

    女士巢穴：为回归的 Boss 机制做好准备。轰炸玛戈玛，到达摩尔多姆抬起的尾巴并移除阿古斯的保护眼，然后再击中它的宝石。

06

沙丘

0 / 3 步骤+

取回女士服装的另一部分。

攻略路线与谜题解法

  1. 01

    无限沙丘：使用水棒柱和锤操作平台穿越沙地。当平台需要平衡时，留下一个英雄作为平衡。

  2. 02

    石廊和吉布多陵墓：在将每个英雄移出入口之前解决房间。燃烧吉布多包裹物，让敌人变得脆弱。

  3. 03

    沙漠神殿：从后面攻击Stalchampion，在暴露的心脏上使用锤子，并在最后的头部阶段建造一个高大的回旋镖图腾。

平衡平台时留下一名英雄作为平衡物。

07

废墟

0 / 3 步骤+

在黑暗中读取颜色。

攻略路线与谜题解法

  1. 01

    虚幻大厦和黑色宫殿：在黑暗隐藏敌人或路线的地方点燃火把。在与活跃英雄一起前进之前，安全地安置第二个英雄。

  2. 02

    孤独的迷宫：将每个英雄与彩色路径相匹配。完整的图腾并不总是穿过特定颜色障碍的正确方法。

  3. 03

    恐怖神庙：及时解救被困的队友。用匹配的英雄攻击普里斯曼图斯的球体，然后将一个英雄扔到暴露的身体上以攻击眼睛。

首领战提示

让每个英雄击中普里斯曼图斯的匹配球体；一旦三个都变暗，就将一个英雄扔到上面以吸引眼球。

实用提示

颜色匹配的平台需要合适的英雄，即使目的地看起来很近。

08

天空王国和莫德夫人

0 / 3 步骤+

打破斯泰拉公主的诅咒。

攻略路线与谜题解法

  1. 01

    漂浮花园、欺骗城堡和龙堡：结合投掷、图腾高度和可用工具。在开始之前检查每个英雄将在哪里完成平台序列。

  2. 02

    天空神庙：准备好挑战并在可用时恢复生命值。莫德会移除你的物品，所以最后的战斗取决于剑、走位和图腾。

  3. 03

    将英雄扔过莫德的屏障，返回她的能量球并爬上颜色匹配的阳伞。收集最后的服装材料并返回海托皮亚完成斯蒂拉的营救。

挑战、服装和试炼巢穴

  1. 01

    在应对挑战变体之前，先完成每个正常阶段。选择能够解决特定限制的服装，例如地形、物品范围或生存。

  2. 02

    在重玩服装的舞台之前检查物质奖励。普通通关、挑战通关和精心制作的服装是不同的收集目标。

  3. 03

    在更新内容可用后进入试炼巢穴。在前进之前清除每一波敌人，节省恢复资源，并将试炼视为与莫德战役不同的耐力挑战。

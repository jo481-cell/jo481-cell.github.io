01

风的去向

0 / 3 步骤+

拯救第一个少女。

攻略路线与谜题解法

  1. 01

    海利亚湖：使用宽阵型来推动宽块，使用箱阵型来推动方形开关。在到达障碍物之前从侧面的洞穴收集力量宝石。

  2. 02

    不归之穴：检查提供的物品并针对分组目标使用适当的阵型。跟踪返回到不同室外位置的洞穴出口。

  3. 03

    海拉鲁城堡：用足够的原力宝石恢复剑的力量，然后清除眼睛障碍。返回幻影加农的能量齐射并在造成眩晕期间进行攻击。

02

东部海拉鲁

0 / 3 步骤+

跟踪沿海调查。

攻略路线与谜题解法

  1. 01

    海岸：携带月亮珍珠到匹配的传送门并比较封锁路线的两个版本。危险的通道在另一边可能会更安全。

  2. 02

    蓝少女村：追踪居民的对话和交流。获得每个要求的物品后，重新访问相关房屋。

  3. 03

    东方神殿：使用月门绕过危险，使用弓对付红眼目标，使用灯对付火把。在需要时交换工具，而不是期望一个项目可以解决整个阶段。

03

死亡之山

0 / 3 步骤+

登上火焰之塔。

攻略路线与谜题解法

  1. 01

    死亡山麓：布置林克以覆盖分组的开关，然后检查舞台设备的开放路径。

  2. 02

    山路：收集锤子并在为其设计的障碍物上使用它。当狭窄路线或远距离控制需要单独移动时，将林克分开。

  3. 03

    火焰之塔：攀爬其室内和室外通道。对抗赫尔玛洛克国王时，先用锤子打碎头盔，然后再攻击裸露的头部。

04

田野附近

0 / 3 步骤+

潜入海拉鲁城堡。

攻略路线与谜题解法

  1. 01

    场地：割草以露出四个开关并使用小组举起大圆木。主路径打开后，重新检查侧面区域。

  2. 02

    沼泽：拿上丹佩的动力手镯并用它移动沉重的障碍物。在离开处理该物体的工具之前，携带必要的物体穿过路线。

  3. 03

    潜入海拉鲁城堡：避开探照灯并将神灯带到贾哈拉。点燃四把火把，在开场时攻击并消灭里面出现的较小的敌人。

首领战提示

在不进入贾哈拉光束的情况下点燃所有四个城堡火把，砍掉他，然后攻击里面的小敌人。

实用提示

十字阵型可以激活附近的四个目标。

05

黑暗世界

0 / 3 步骤+

到达黑暗神殿。

攻略路线与谜题解法

  1. 01

    失落的森林：比较世界之间的标志和路径，并使用灯来寻找黑暗的通道。标记门户位置以避免重复相同的循环。

  2. 02

    卡卡里科村：搜查所有十名盗贼的房屋、后门、灌木丛和地下房间，然后将他们带到围栏。

  3. 03

    黑暗神殿：互联世界之间的坐标切换。返回幻影加农的真实能量齐射，而不是追逐每个图像。

06

怀疑的沙漠

0 / 3 步骤+

探索沙漠的路线。

攻略路线与谜题解法

  1. 01

    怀疑沙漠：与格鲁多长老和守卫交谈，然后在进入迷宫前阅读风的线索。遵循指示的相对于风的方向。

  2. 02

    沙漠神殿：在返回中心障碍物之前检查树枝上是否有工具和钥匙。保留足够的原力宝石来增强最后的突破屏障攻击。

  3. 03

    金字塔：使用颜色与大莫多姆尾巴相匹配的林克。 Boss分开后继续匹配颜色。

07

冰冻海拉鲁

0 / 3 步骤+

登上风之塔。

攻略路线与谜题解法

  1. 01

    冰冻海拉鲁：轰炸隐蔽的洞穴入口并拉动杠杆打开攀爬。在冰天雪地的战斗中小心控制移动。

  2. 02

    冰之神殿：在必须按住的开关上留下雕像，并对分组的楼层开关使用十字形。在假设房间没有机械装置之前检查松动的罐子。

  3. 03

    风之塔：爬上侧景房间并协调单独的平台。击败塔楼守护者并完成塞尔达的营救，然后前往天空区域。

08

诸天之境

0 / 3 步骤+

对抗瓦蒂。

攻略路线与谜题解法

  1. 01

    天堂之境：在将队形进行跳跃或狭窄交叉之前研究平台运动。在移至下一个屏幕之前恢复孤立的林克。

  2. 02

    黑云：完成暗影林克遭遇战并恢复黑镜。当敌人停止响应另一个林克时，匹配所需的颜色。

  3. 03

    风之宫：对瓦蒂的龙卷风使用炸弹。后期从他上方发射，向下攻击穿过开口，从竞技场下方攻击。

09

逃亡与加农

0 / 3 步骤+

封印最后的威胁。

攻略路线与谜题解法

  1. 01

    击败瓦蒂后与塞尔达一起逃亡；冒险还有最后的对抗。让团队一起通过崩溃的路线。

  2. 02

    传送到黑暗世界时，避开加农的三叉戟并清除敌人。在他的恢复窗口期间返回攻击。

  3. 03

    在塞尔达准备光球时保护她。返回来袭的射弹，然后通过她的球体向加农射出一支箭。

进度检查点

首领战提示

当塞尔达准备她的球体时，归还加农的射弹。穿过光球向加农发射一支箭。

实用提示

使用宽阵型进行剑覆盖，而无需站在三叉戟的路径上。

收集指南

阶段完成和可选奖励

  1. 01

    目标是在每个阶段收集至少 2,000 颗原力宝石，以便四剑能够打破其结局障碍。如果时间较短，请探索未开放的支线路线，而不是反复撞击障碍物。

  2. 02

    收集当前阶段的心之容器和防护升级，记住这些不会在整个战役中形成永久的二十心库存。

  3. 03

    将 Tingle 塔活动和其他多人游戏模式与二十四个故事阶段分开对待。它们的可用性取决于模式和播放器设置。

01

奥登去森林

0 / 3 步骤+

恢复法隆的光芒。

攻略路线与谜题解法

  1. 01

    完成奥登的钓鱼和村庄任务，然后以狼的身份收回剑和盾。与米德娜一起逃离城堡后，使用感官追踪气味并探测灵魂。

  2. 02

    收集法隆的光之泪以恢复人类形态。在森林神庙中，释放猴子并使用它们摆动的链条到达新的树枝。

  3. 03

    疾风回旋镖可以把炸弹送到远处的目标。先炸掉迪亚巴巴两侧的嘴，再在同一次投掷中依次锁定乌克携带的炸弹和中央的嘴。头部倒下后攻击眼睛。

02

卡卡利科与咕隆族

0 / 3 步骤+

营救孩子们并进入矿井。

攻略路线与谜题解法

  1. 01

    恢复埃尔丁的光芒并返回奥登参加博的相扑课并获得铁靴。停止对戈隆冲锋时穿上靴子。

  2. 02

    在矿井中，靴子附着在磁性表面上并按住重型开关。只有在检查林克将降落的位置后才释放它们。

  3. 03

    取得弓和三位长老的钥匙碎片。射中菲鲁斯的额头后，穿上铁靴，抓住他身后拖着的一条锁链并用力拉，直到将他绊倒。

03

湖底下

0 / 3 步骤+

恢复最后一个融合之影。

攻略路线与谜题解法

  1. 01

    扭曲死亡山的炽热岩石，解冻佐拉的领地。恢复拉娜鲁的光芒，完成马车护送，并从鲁特拉的坟墓中获得佐拉铠甲。

  2. 02

    购买水炸弹并进入湖床神庙。转动中央楼梯将水引入未填充的房间，并跟踪哪一侧已供水。

  3. 03

    获得爪射。将莫菲尔的触手眼拉向你，然后在游泳阶段上升到其背部上方并抓住裸露的眼睛。

04

神圣树林

0 / 3 步骤+

打破狼的诅咒。

攻略路线与谜题解法

  1. 01

    将米德娜带到塞尔达，然后以狼的形式返回法隆。跟随骷髅小子的灯笼和音乐穿过圣林，当他可以到达时进行攻击。

  2. 02

    在守护者谜题中，雕像会根据它们的规则反映你的动作。如果你困住了雕像，请从两个目标方格返回并重置。

  3. 03

    拔出大师剑解除强制变形。在以后的探索中，使用自愿的狼变形来追踪气味并到达挖掘路线。

05

沙漠监狱

0 / 3 步骤+

找到暮光之镜。

攻略路线与谜题解法

  1. 01

    与奥鲁交谈并向费耶展示他的沙漠大炮之旅备忘录。穿过布尔布林营地并进入仲裁者之地。

  2. 02

    利用狼的感官追踪四位坡并归还他们的火焰。变回人类形态进入机械室并收集旋转器。

  3. 03

    沿着铁轨骑着旋转车，穿过沙子击中斯托洛德的脊椎。在塔阶段，在铁轨之间跳跃以躲避火球并发射到浮头中。

06

雪峰遗址

0 / 3 步骤+

恢复镜子碎片。

攻略路线与谜题解法

  1. 01

    将阿希的草图展示给拉利斯，然后用珊瑚耳环钓一条溪鱼。记住它的狼的气味，然后沿着山路到达耶托。

  2. 02

    在耶塔的指导下搜索宅邸的侧室。使用炮弹和大炮来打破大冰障并获得球和链。

  3. 03

    用球链打破暴雪外层的冰。观察地板反射，预测掉落的冰块，清除障碍物并攻击她裸露的身体。

07

时之神殿

0 / 3 步骤+

将雕像放回原位。

攻略路线与谜题解法

  1. 01

    沿着鲁斯尔的路线返回圣林，打开通往神殿的门。上升之前请注意入口处丢失的雕像。

  2. 02

    收集统治权杖并护送大型雕像返回。利用其重量控制开关和秤，并利用锤子打破障碍。

  3. 03

    用弓射中阿莫戈玛睁开的眼睛。命令附近的雕像将其压碎，然后消灭大型生物被摧毁后留下的较小生物。

08

上面的城市

0 / 3 步骤+

找到最后一个碎片。

攻略路线与谜题解法

  1. 01

    完成隐藏村庄和伊利亚的记忆序列以恢复统治权杖。跟随沙德的古代天空之书搜索，收集天空字符并让费耶修理大炮。

  2. 02

    在天空之城内，对有效目标使用抵御强风的靴子和利爪射击。第二个爪射让你在目标之间移动而不着陆。

  3. 03

    用靴子将阿尔戈洛克拉下来，直到它的盔甲破裂。爬上飞行目标，在龙喷火时移动到龙身后，抓住它背上的弱点。

09

黄昏的宫殿

0 / 3 步骤+

重新组合镜子并面对赞特。

攻略路线与谜题解法

  1. 01

    归还所有镜子碎片并进入暮光宫殿。从侧翼回收两个太阳球并将其带回入口。

  2. 02

    移动太阳时，保持在追击手的前面。需要升高楼梯时，将其放入地板插座中，然后在继续之前将其取出。

  3. 03

    凭借强大的剑，斩断黑暗的屏障。赞特的战斗重温了早期的竞技场：重复使用匹配工具，然后在最后的竞技场惩罚他疲惫不堪的旋转攻击。

10

海拉鲁城堡

0 / 3 步骤+

结束占领。

攻略路线与谜题解法

  1. 01

    清理庭院路线以获取钥匙并进入城堡。利用狼的感官来识别穿过欺骗性地板部分的安全路线。

  2. 02

    归来拥有塞尔达用剑进行的能量射击。对抗野兽加农时，以狼的身份停止冲锋，将其击倒后进行攻击。

  3. 03

    在骑马追逐中，让加农多夫对准塞尔达的箭。在最后的剑决斗中，躲避攻击并在恢复过程中反击。

首领战提示

归来拥有塞尔达的能量，像狼一样与野兽加农摔跤，让塞尔达在马背上保持一致，然后躲避加农多夫的剑和反击。

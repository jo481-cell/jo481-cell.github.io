01

节日和深林神社

0 / 3 步骤+

恢复土元素。

攻略路线与谜题解法

  1. 01

    营救埃兹洛，在树桩处收缩并进入米尼什村。在尝试理解村民之前吃掉贾伯坚果，然后找到迷你尺寸的神社入口。

  2. 02

    使用蘑菇手柄作为发射器并旋转枪管以连接其出口。阵风罐可以清除蜘蛛网和灰尘，并将睡莲叶推过水面。

  3. 03

    对抗大绿楚楚，吸走基地直到失去平衡。远离坠落的身体，然后攻击其裸露的头部。

02

克雷内尔山和火焰洞

0 / 3 步骤+

恢复火元素。

攻略路线与谜题解法

  1. 01

    第一豆用普通水，特级爬豆用山上矿泉水。购买握环，到达梅拉里并留下破损的刀片进行修理。

  2. 02

    乘坐矿车并收集帕奇手杖。它会翻转翻倒的推车并装填孔，将林克发射到更高的壁架上。

  3. 03

    用手杖翻转格利罗克的外壳，爬上它的脖子并敲击水晶。在熔岩上升、颈部变得危险之前返回安全地面。

03

剑与卡斯特荒野

0 / 3 步骤+

到达风之遗迹。

攻略路线与谜题解法

  1. 01

    收集修复好的白剑，并在圣域注入两种元素。在标记的方块上为剑充电，为配对开关创建副本。

  2. 02

    用唤醒蘑菇唤醒雷姆以获得飞马靴子。冲过沼泽，不要在不安全的地面上停下来。

  3. 03

    在卡斯托荒野收集弓和金色金石。完成所需的雕像融合，打开通往风之遗迹的路线。

04

风之堡垒

0 / 3 步骤+

寻找下一个线索。

攻略路线与谜题解法

  1. 01

    搜索废墟的单独入口并在链接的开关上使用剑副本。收集鼹鼠手套，挖掘柔软的墙壁并发现隐藏的通道。

  2. 02

    对抗马扎尔，射击一只手的眼睛并攻击被击晕的手。双手废去，收缩入头。

  3. 03

    在里面，挖到脆弱的柱子并摧毁它，然后重复这个循环。之后拿风之笛：风元素在别处。

首领战提示

射击双手的眼睛，砍断它们，然后缩进马扎尔的头部并摧毁其脆弱的支柱。

实用提示

风系不在这里，陶笛开启快速旅行。

05

书籍和水滴神庙

0 / 3 步骤+

恢复水元素。

攻略路线与谜题解法

  1. 01

    归还图书馆逾期的三本书。这本书的任务包括动力手镯，并最终让你到达图书馆获得脚蹼。

  2. 02

    进入湖中的迷你传送门并在冰冻神殿中航行。改变到达冰面的光线，然后使用火焰灯笼打开之前冰冻的路线。

  3. 03

    用剑归还大章鱼的岩石。当它冻结时，绕到后面并点燃它的尾巴；需要时用灯笼清除黑暗。

06

皇家墓穴和云顶

0 / 3 步骤+

找到风族。

攻略路线与谜题解法

  1. 01

    注入水元素后，沿着皇家谷路线完成皇家墓穴。使用剑副本来切换单个林克无法控制的开关。

  2. 02

    将古斯塔夫国王的金色金石带到面纱瀑布并在水流源头融合。跟随攀登云端。

  3. 03

    探索两个云层，击败金色敌人并完成所有五个金色融合。清除的旋风通向风族的塔楼。

07

风之宫

0 / 3 步骤+

获得风元素。

攻略路线与谜题解法

  1. 01

    收集大鹏斗篷并使用扩展跳跃来跨越云平台。在跨越长距离发射之前，观察移动平台的整个周期。

  2. 02

    室外攀登与室内开关室交替进行。在进行多开关布置之前，在标记的图块上创建所需数量的剑副本。

  3. 03

    在较大的吉尔格上，将复制品与暴露的眼睛相匹配并一起攻击。需要时跳到较小的吉尔格身边，击中它的眼睛并跳上扫过的尾巴。

本章参考资料
  • 地下城 5：风之宫殿 ↗

进度检查点

首领战提示

将副本与红色吉尔格的眼睛相匹配；在蓝色的那只身上，击中它的眼睛并跳动它扫过的尾巴。

实用提示

大钥匙可以打开不止一扇大门。

08

黑暗海拉鲁城堡

0 / 3 步骤+

恢复四剑并到达塞尔达。

攻略路线与谜题解法

  1. 01

    注入最后的元素来恢复四剑。对黑暗海拉鲁城堡内的石化人和四副本开关使用它的力量。

  2. 02

    穿过城堡的分支寻找钥匙并重新连接中央上升道。在走上最后的楼梯之前，请补充心中的能量并安排治疗。

  3. 03

    在终场铃声响起前击败三个黑坚果。使用受控反击和后方攻击；长时间盘旋而不进行攻击可能会导致计时顺序失败。

09

瓦提的三种形态

0 / 3 步骤+

打破塞尔达的诅咒。

攻略路线与谜题解法

  1. 01

    摧毁瓦蒂周围的眼睛，并在需要时用狂风罐去除它们的黑色覆盖物。仅在保护消失后才攻击中央眼。

  2. 02

    在下一个形态中，使用箭头露出脆弱的眼睛，然后在匹配的排列中创建剑副本并一起攻击。

  3. 03

    对于瓦蒂之怒，用帕奇翻转手臂，收缩并进入其中。在黑暗中使用灯笼摧毁里面的异眼；最后将四个射弹和四个林克一起返回。

本章参考资料
  • 最终首领 ↗

进度检查点

首领战提示

与帕奇一起翻转每只埋在地下的手臂，收缩到里面并摧毁其独特的眼睛。在黑暗中使用灯笼；最后返回四个射弹和四个林克。

实用提示

不要将第一次胜利误认为是结局。

金石、雕像和心形

  1. 01

    在完成每个主要项目后重新访问城镇并融合可用的金石。按照地图动画找到打开的奖励，而不是将融合算作收集的宝箱。

  2. 02

    保存卡洛夫的贝壳，以寻找收藏中仍然缺失的人物。有些人物只在结局后出现；完成收藏即可获得相关的心形奖励。

  3. 03

    使用手套、脚蹼和斗篷重新访问以前无法进入的洞穴和壁架。将心脏碎片与通过特殊奖励收到的完整容器分开追踪。

培训、瓶子和容易错过的帮助

  1. 01

    当新装备可用时拜访剑术老师。学习八虎卷术，并单独查看额外的训练改进。

  2. 02

    完成神秘墙融合来聚集戈龙并打开他们的洞穴奖励。结束后返回，进行最后的盾牌相关交换。

  3. 03

    在通过融合实现的早期访问期间，用狂风罐帮助生病的风部落居民。推迟到正常的游戏后期访问可能会失去光箭奖励。

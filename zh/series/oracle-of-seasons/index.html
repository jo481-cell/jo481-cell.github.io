01

粗糙的根地牢

0 / 3 步骤+

恢复第一个精华。

攻略路线与谜题解法

  1. 01

    在独立文件中从英雄洞窟恢复剑，然后唤醒玛库树。使用粗糙钥匙打开霍伦村北部的树地牢。

  2. 02

    收集种子包并使用余烬种子点燃火把。当门保持关闭状态时，清除敌人后推动方块。

  3. 03

    从三颗火球蔓延的外侧接近阿奎门图斯。敲击它的角，收集心脏和精华，然后返回玛库树的下一条线索。

02

冬天与蛇的遗骸

0 / 3 步骤+

获得能量手镯。

攻略路线与谜题解法

  1. 01

    沿着通往苏布罗西亚的传送门并获得季节之杖的冬季力量。站在树桩上改变季节；厚厚的积雪在无法通行的岩架上开辟了道路。

  2. 02

    拜访霍莉获取铲子并到达蛇的遗骸。取回电源手环并将锅放在开关上，不要扔掉唯一可用的锅。

  3. 03

    给多东戈喂一颗炸弹，在充气时将其举起，然后将其扔到尖刺上。用剑攻击它的装甲身体并不能解决这场战斗。

03

夏天和毒蛾的巢穴

0 / 3 步骤+

学习跳跃。

攻略路线与谜题解法

  1. 01

    找到水闸钥匙并打开沼泽的水路。在苏布罗西亚，给罗莎丝带并跟随她到达夏季塔。

  2. 02

    将季节改为夏季，以便藤蔓生长到地牢入口。收集大鹏的羽毛并用它穿过深坑并到达开关。

  3. 03

    对抗莫苏拉，跳过攻击，同时保留安全着陆方块。在其可到达的通道中进行攻击，并在较小的敌人挤满平台之前将其消灭。

04

沉没之城与舞龙

0 / 3 步骤+

获得弹弓。

攻略路线与谜题解法

  1. 01

    通过潜水大师的脚蹼测试。探索库科山和苏布罗西亚以获得泉水之力，然后取回龙钥匙。

  2. 02

    使用弹弓激活远处的种子开关。选择合适的种子：余烬种子可以点燃火把，而其他种子则可以解决不同的谜题。

  3. 03

    避开戈玛的爪子并等待它的眼睛睁开。将余烬或香味种子射入眼睛，然后在下次接近之前重新定位。

05

秋天和独角兽的洞穴

0 / 3 步骤+

掌握磁力运动。

攻略路线与谜题解法

  1. 01

    获得秋天的力量并改变眼镜湖的季节以暴露湖底的路线。将种子和治疗带入独角兽的洞穴。

  2. 02

    磁性手套在吸引和排斥之间切换。将极性与锚或金属球相匹配，并进行短暂调整以使球保持在预期路径上。

  3. 03

    将带刺的金属球射入 Digdogger 中。 Boss 分裂后继续使用它来对付较小的生物，同时保持林克远离它们的移动。

06

塔姆遗址和古代遗址

0 / 3 步骤+

找回魔法回旋镖。

攻略路线与谜题解法

  1. 01

    收集四颗形状的珠宝并将它们放置在塔姆废墟大门中。利用季节变化穿越废墟并遵循失落森林的指示。

  2. 02

    魔法回旋镖在投掷后可以控制方向。将其绕着墙壁弯曲以操作无法直线击中的开关。

  3. 03

    用回旋镖击中曼罕德拉开放的花朵。一旦它的保护形态破裂，就切换到剑并追击暴露的核心。

07

海盗和探险家的地穴

0 / 3 步骤+

取得洛克鸟羽衣。

攻略路线与谜题解法

  1. 01

    找回萨马萨沙漠中海盗丢失的钟并让苏布罗西亚铁匠修理它。返回给船长即可开通西线。

  2. 02

    在适当的季节到达墓地。在探险家的墓穴内，当鬼魂威胁要让你返回入口时，立即点燃火把。

  3. 03

    持有大鹏斗篷时，跳跃范围会延长。用它来跨越更长的间隙，并在砍掉格利奥克的头后躲避它的冲击波。

08

剑盾迷宫

0 / 3 步骤+

完成八个精华。

攻略路线与谜题解法

  1. 01

    通过苏布罗西亚触发火山喷发，然后通过改变的圣殿遗迹返回。沿着新路线和季节性藤蔓到达地牢门户。

  2. 02

    收集超级弹弓并携带冰晶穿越矿车路线。将水晶放入正确的竖井中以冷却下层的熔岩。

  3. 03

    对抗美杜莎头，用大鹏斗篷跳过光束和旋转球体。在球体攻击后使用飞马种子将其击晕，然后用剑攻击。

09

奥诺克斯城堡

0 / 3 步骤+

营救丁。

攻略路线与谜题解法

  1. 01

    在第八个精华之后收集巨大的玛库种子并进入奥诺克斯的城堡。在尝试前进之前，先击败每个房间中所需的敌人。

  2. 02

    对奥诺克斯使用带电剑攻击。当丁的水晶阻挡你的接近时，用季节之杖移动它而不是击打它。

  3. 03

    面对龙形态时，避开手掌的拍击，跳上放低的手并攻击额头的宝石。记下通关后显示的密码，用它开始《不可思议的果实 时空之章》的联动冒险。

联动游戏和永久升级

  1. 01

    使用《大地之章》的通关密码，在《时空之章》中继续冒险；也可以反过来，用《时空之章》的密码开始联动的《大地之章》。顺序会影响部分遭遇和密码的接收角色。

  2. 02

    完成两个游戏中的每个秘密交换，并将生成的密码返回给 Farore（如果适用）。将环转移与故事链接秘密分开。

  3. 03

    在联动游戏中，带着游戏后期装备返回英雄洞窟，迎接更大的挑战。击败 Onox 并没有完成 Oracle 的共同结局。

心、嘎莎树和同伴

  1. 01

    在不同季节重新访问地点：冰冻的水、树叶覆盖的洞、蘑菇和夏季藤蔓可以改变获得奖励的机会。

  2. 02

    跟踪固定心脏位置与涉及嘎莎坚果或枫树的奖励分开。随机奖励可能需要多次尝试，并且不是缺失的地图标记。

  3. 03

    将动物伙伴记录到您的文件中。同伴区域不同，因此为其他动物显示的路线可能与您的地形不匹配。

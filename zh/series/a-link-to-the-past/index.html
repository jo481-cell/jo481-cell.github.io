01

光之世界 · 雨、城堡和秘密通道。

雨夜救援

出发前不需要任何物品

奖励剑、盾、提灯与圣堂的心之容器

打开本章独立页面 ↗

  1. 打开屋内的宝箱拿走灯笼。冒着雨出去，前往北边的城堡。

  2. 东园中，提起孤灌木，落入洞中。与你的叔叔交谈以获得剑和盾牌，然后沿着地下通道进入庭院。

  3. 进入城堡，进入地牢并从守卫那里收集钥匙。拿起回旋镖来固定敌人。

  4. 向塞尔达牢房外的球链守卫扔罐子，或者在他的攻击之间进行打击。收集他的大钥匙，解锁牢房并与塞尔达交谈。

  5. 返回王座。将家具推到右边；穿过黑暗的通道。从宝箱中取出钥匙，然后从下水道的老鼠身上取出钥匙。

  6. 向上推动通道的中央块。在最后一个房间中，拉动右侧的控制杆。听智者之言，取心之容器。

本章提示 +

通往塞尔达的道路从守卫的门旁边开始。

揭晓解决方案

绕过右边的城堡，举起孤立的灌木丛。救援结束后，将王座后面的家具从左边推开。

02

光之世界 · 卡卡利科村成为您的大本营。

在卡卡利科村中做好准备

出发前塞尔达在庇护所

奖励网、瓶子和与 Sahasrahla 的会面

打开本章独立页面 ↗

  1. 向西前往 卡卡利科村 并询问 Sahasrahla。他的藏身处靠近东部废墟。

  2. 留100卢比给村里的商人。购买的瓶子可以让你运输药水、仙女或蜜蜂。

  3. 绕过酒馆向北走，可以使用它的后门。打开这个小房间的宝箱可以获得第二瓶。

  4. 与他家里生病的孩子交谈。用网捕捉仙女，选一个空瓶子；她会在失败后帮助你。

  5. 使用炸弹探索村庄的水井和盗贼藏身处的地下室。使用地图的红心过滤器标记您收集的心之碎片。

  6. 前往东方神殿西南的小房子。与 Sahasrahla 交谈，然后前往宫殿入口。

本章提示 +

一个经过充分探索的村庄会给你很多生存的机会。

揭晓解决方案

从商人那里买瓶子，进入酒馆后面，与生病的孩子交谈以获得网。

光之世界 · 第一个吊坠·学会瞄准。

东方神殿

出发前剑 · 灯笼

奖励弓、勇气吊坠和天马靴

打开本章独立页面 ↗

  1. 提起中央锅即可打开门。使用壁龛作为庇护所，穿过炮弹走廊。

  2. 在无障碍侧翼收集地图和指南针。找到中央的大宝箱；您将带着大钥匙返回。

  3. 在东翼，穿过黑暗的房间。从骷髅房的右上角提起锅。

  4. 前往西厢房。击败敌人，包括觉醒的独眼雕像怪。提起他们看守的锅并使用楼层开关获得大钥匙。

  5. 返回大宝箱并打开它。在穿过北门之前收集罐子下面的箭头。

  6. 唤醒独眼雕像怪并攻击他们睁开的眼睛。红色独眼雕像怪需要箭头。收集掉落的钥匙并激活最后房间的开关。

  7. 击败阿莫斯，然后拿走心脏和吊坠。切勿在没有获得这两种奖励的情况下离开首领房间。

  8. 返回他的庇护所获取天马靴。它们可以让你击中物体并拿到图书馆的书。

本章提示 +

大宝箱不是你的第一个目的地。

揭晓解决方案

击败西边房间的敌人，到达被泡泡怪包围的锅子。提起它并踩下开关即可露出大钥匙。

首领 阿莫斯骑士 ↗

当六个雕像活过来时射击。在巡视期间留在后面；当他们冲锋时，请移到一边。最后一个骑士跳到你身上：移动，然后射击。

光之世界 · 第二个吊坠·沙子之下的力量。

沙漠神殿

出发前天马靴 · 穆多拉之书 · 灯笼

奖励力量手套及挂件

打开本章独立页面 ↗

  1. 卡卡利科村以南，用靴子撞到图书馆的书架上。以穆多拉之书为例。

  2. 在西南的沙漠中，阅读这本书的中央铭文。当通道打开时进入。

  3. 探索第一组的西北部。碰到支撑物，按住钥匙使其掉落。

  4. 使用此钥匙向东；消灭敌人并穿过弹丸走廊到达大钥匙。

  5. 返回西边。隐藏在锅子下面的开关可以打开大宝箱室：拿走手套。

  6. 西南出口；沿着壁架走下去，找到 心之碎片。往回走，把北门前的石头抬起来。

  7. 在飞瓷砖的房间之间移动，把钥匙放在花盆下面。在最后一个房间里，点燃四把火把。

  8. 击败三个兰莫拉，然后拿走心之容器和吊坠。

本章提示 +

外部出口是地牢的一部分。

揭晓解决方案

在西翼取得力量手套，走到外面的平台，再前往白色岩石后方的北侧入口。

首领 兰莫拉斯 ↗

留意移动的沙子。当它们出现时，打击它们的头部，远离对角碎片。最后一条虫子扔了更多的石头：给它空间。

光之世界 · 你第一次看到另一个海拉鲁。

攀登死亡之山

出发前力量手套 · 灯笼

奖励魔法镜并访问赫拉之塔

打开本章独立页面 ↗

  1. 在庇护所北面，抬起阻挡通往山洞的石头。提着灯笼进去。

  2. 到了山洞里，陪老者走到出口。避开洞并留在可通行的路径上。

  3. 老头给你的是魔法镜。它的庇护也可以让你恢复生命。

  4. 爬上外面的梯子和小路。小心从斜坡上滚下来的岩石。

  5. 踏上眼镜岩附近的扭曲瓷砖。没有月之珍珠，林克就变成了一只兔子。这是目前预计的情况。

  6. 在岩石的位置使用镜子。走心之碎片，然后下到赫拉之塔。

本章提示 +

兔子仍然可以使用镜子。

揭晓解决方案

在暗之世界中，站在光之世界中眼镜岩的位置并使用魔法镜。您将出现在岩石顶部。

光之世界 · 第三个吊坠·别忘了珍珠。

赫拉之塔

出发前魔法镜 · 灯笼

奖励月之珍珠和最后一个吊坠

打开本章独立页面 ↗

  1. 降低蓝色块并下降。拿起小钥匙，然后调整水晶，这样你就可以回去了。

  2. 收集地下城地图。水晶开关改变彩色屏障；星形开关改变地板孔。

  3. 打开西北通道，从飞舞的瓷砖中幸存下来，然后到达有四个火把的房间。点亮它们即可显示大钥匙。

  4. 回去并走上面的楼梯。将甲虫从洞中推开，然后收集指南针。

  5. 在上层，使用星星打开正确位置的洞。从其北边掉落并打开月之珍珠的宝箱。

  6. 再次走楼梯。在摩尔多姆面前将心放在罐子下治愈，然后进入他的竞技场。

  7. 胜利后，振奋精神，垂饰。离开山前还要检查珍珠是否在库存中。

本章提示 +

星星移动洞，跌倒可以帮助你。

揭晓解决方案

在大宝箱上方的地板上，激活旋转火焰附近的星星。从保险杠北边接近保险杠以北的洞并落下。

首领 莫尔多姆 ↗

只击中了它的尾尖。保持平台中心，避免边缘交易。一次跌倒改变了他的生活；通过楼梯返回。

光之世界 · 这场胜利开启了第二次冒险。

大师之剑和魔法师

出发前三个吊坠 · 月之珍珠

奖励大师之剑并持久进入黑暗世界

打开本章独立页面 ↗

  1. 在迷失森林中，到达基座空地。有了三个吊坠，去掉大师之剑；树林里的其他剑都是诱饵。

  2. 跟随塞尔达的召唤前往庇护所。目前，救援工作正在城堡顶部继续进行。

  3. 在城堡的上层平台上，用大师之剑击中魔法屏障并进入塔楼。

  4. 上去，照亮黑暗的房间并消灭守卫以获得钥匙。罐子充当武器并容纳资源。

  5. 与塞尔达的场景结束后，剪开阿加尼姆身后的窗帘即可进入他的竞技场。

  6. 返回他适当的攻击，直到他被击败。您被传送到金字塔的顶部。

  7. 如果林克仍然是兔子，请返回赫拉获取月之珍珠。镜子返回光并留下一个临时的返回入口。

本章提示 +

巫师亲自为您提供投射物。

揭晓解决方案

用剑把他的大能量球还给他。远离碎片射弹和闪电。

首领 阿加尼姆 ↗

站在他面前把大球还回去。当它移动到顶部中心召唤闪电时，离开它的轴。剑并没有直接伤害他。

暗之世界 · 水晶I·开路用魔法锤。

黑暗神殿

出发前月之珍珠 · 弓 · 炸弹 · 琪琪 110 卢比

奖励魔法锤和第一晶体

打开本章独立页面 ↗

  1. 从金字塔出发，穿过东部废墟。付钱让猴子跟着你，然后打开宫殿；避免那些把他吓跑的打击。

  2. 使用开关拿到左边的地下室钥匙。右边，传送器通向戈里亚斯房间和地图。

  3. 轰炸地图室附近破裂的墙壁。要击中红色戈里亚，请发射一支箭，然后移动，以便敌人将您反射到其路径中。

  4. 返回中央路线。在标记的间隙下降到较低的水平，到达大钥匙宝箱。使用楼层地图来追踪连接。

  5. 快速穿过倒塌的桥。在迷宫中，拿到东南方向的钥匙，然后轰炸东墙，到达魔法锤。

  6. 在攻击乌龟敌人之前，先用魔法锤翻转它们。收集指南针和下层钥匙，然后返回开关和绿色雕像。

  7. 按住雕像上的按钮，射击绿眼睛，然后下降。水晶和传送器通向 Boss。

  8. 击败赫尔玛索尔，获得勇气和水晶。 魔法锤现在打开许多外部通道。

本章提示 +

一座雕像隐藏着最后一条路。

揭晓解决方案

在魔法锤之后，将一个雕像放在开关上，然后用箭头瞄准绿色雕像的眼睛以打开下降。

首领 赫尔马恐龙王 ↗

用魔法锤或炸弹摧毁他的面具。一旦发现绿色宝石，就使用剑或箭。当他摆动尾巴时，避开他的尾巴。

暗之世界 · 水晶 II · 在一个世界中行动改变另一个世界。

沼泽神殿

出发前魔法锤 · 脚蹼 · 魔法镜

奖励钩索和第二晶体

打开本章独立页面 ↗

  1. 在光之世界东北部的佐拉领地，以500卢比购买脚蹼。它们使穿过宫殿成为可能。

  2. 前往暗之世界的南部遗迹。使用魔法镜，进入相应的光之世界建筑物并拉动右侧的控制杆。

  3. 退出并返回镜像门户。进入黑暗宫殿，渡过水面，消灭敌人，揭开第一把钥匙。

  4. 下去，在头骨下寻找钥匙并启动阀门。 魔法锤可以让您降低障碍物。

  5. 从中央水池向西北打开，将阀门推向左侧。设置水晶降低橙色方块，然后游入西南航道。向西，将底部的方块推向左侧，然后将中央的方块向上推。上;掉进东北洞，打开东边的宝箱。

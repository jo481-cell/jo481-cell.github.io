01

逃亡和素通遗址

0 / 3 步骤+

了解 托力 可以做什么。

攻略路线与谜题解法

  1. 01

    逃离城堡时复制桌子、盒子和床。建造短而稳定的楼梯以通过守卫并到达素吞地区。

  2. 02

    在裂缝中营救特里的朋友，然后进入苏通废墟。使用绑定移动重型障碍物并从无人防守的方向攻击林克冒名顶替者以获得剑士形态。

  3. 03

    对抗地震距骨，用“绑定”将发光球拉出并攻击它。当球体改变位置时重复此操作，远离 Boss 的猛击。

02

格鲁多沙漠

0 / 3 步骤+

获得进入圣所的权限。

攻略路线与谜题解法

  1. 01

    帮助多纳解决较小的沙漠裂痕。在隐秘洞穴中，操作排出阻塞圣所路线的沙子的机制。

  2. 02

    了解所需的雕像回声并使用地牢的线索来选择它们。霍尔米尔可以挖掘合适的地面，开辟攀岩回声无法开辟的路线。

  3. 03

    从林克冒名顶替者处获取弓。在莫格里夫冲锋期间，在其路径上放置一座雕像以使其发生碰撞，然后在其被击晕时进行攻击。

03

贾布尔沃特斯

0 / 3 步骤+

重新团结佐拉社区。

攻略路线与谜题解法

  1. 01

    帮助佐拉社区并使德拉德和库沙拉团聚。击败贾布贾布骗子，然后穿过裂缝进入废墟。

  2. 02

    激活五个颜色的开关以升高中央水柱。探索侧枝并利用水生回声来对付水下的敌人和障碍物。

  3. 03

    打破 Vocavor 背部的生长物，同时避开它的漩涡。崩溃后攻击暴露的弱点，必要时返回喘息空间。

04

海拉鲁城堡的裂缝

0 / 3 步骤+

救出国王。

攻略路线与谜题解法

  1. 01

    完成格鲁多和贾布尔地区后返回海拉鲁城堡镇。进入裂缝并绕过守卫的视线移动。

  2. 02

    使用开关和火把上的回声来打开城堡的树枝。当召唤生物处理附近的敌人时，绑定可以重新定位障碍物。

  3. 03

    对抗加农回声，躲避长矛和火蝙蝠。通过定时挥剑返回能量球或使用安全恢复窗口进行强烈回声攻击。

05

埃尔丁火山

0 / 3 步骤+

获得迪恩的认可。

攻略路线与谜题解法

  1. 01

    帮助达斯顿解决哥伦人的问题，然后沿着火山路线前进。使用耐热穿越回波并避免将易燃物体放置在熔岩上。

  2. 02

    击败使用炸弹的林克冒名顶替者并获得新武器。清除破裂的障碍物，并将移动的熔岩平台与攀爬回声结合起来。

  3. 03

    用绑定拉动伏尔瓦吉亚的绿色项链，将其击晕。在开场时攻击，然后在龙在其他地方爆发之前移动到安全平台。

  3. 03

    给戈玛的腿部水晶通电，将其击落。攻击暴露的眼睛，然后准备另一个电气开口，同时避开其网并召唤敌人。

07

赫布拉和拉奈鲁神庙

0 / 3 步骤+

获得娜如的认可。

攻略路线与谜题解法

  1. 01

    在康德的指导下攀登赫布拉峰并做好防寒准备。使用火焰回声清除冰块和稳定物体以阻挡破坏性的风。

  2. 02

    使用 Bind 携带神庙的温度球并将其放置在正确的基座上。在运输必须保持热或冷的球体之前，请堵住通风口。

  3. 03

    用火对付 Skorchill 的冰冷头盔，用冰对付火热头盔。一旦头盔破损，就会攻击身体，然后在其保护措施发生变化时进行适应。

08

永恒森林

0 / 3 步骤+

寻找林克。

攻略路线与谜题解法

  1. 01

    获得全部三位女神制裁后，进入永恒森林并找到远古宝珠。在寻找其他基座之前先了解它的回声。

  2. 02

    使用三角形排列作为地图线索，并在六个基座上各放置一个球体。沿着打开的路线进入寂静的废墟。

  3. 03

    处理假塞尔达召唤的敌人，创造攻击机会并击败她。救出勇者林克，准备与他一起完成最后的冒险。

09

努尔体内

0 / 3 步骤+

与林克并肩作战。

攻略路线与谜题解法

  1. 01

    归还林克的武器，一起进入努尔的身体。塞尔达的角色转变为移动、回响和束缚，而林克则进行直接剑攻击。

  2. 02

    为“林克”创建路线并使用“绑定”将障碍物或附属物拉到可触及的范围内。分离时，利用水生回声和小心穿越来重逢。

  3. 03

    将 Null 的手臂向外拉，以便 Link 可以砍断它们。清除召唤的敌人，重复穿过不断变化的竞技场并帮助Tri移除暴露的最终核心。

首领战提示

用同步能力拉住努尔的手臂，让林克斩断它们；消灭召唤出的敌人，最后和托力一起拉出核心。

实用提示

当战斗复制品消失时继续更换它们；塞尔达的角色始终保持活跃。

回声、心灵和地区任务

  1. 01

    当你第一次击败或发现回声的来源时学习回声；看到一个生物是不够的。使用回波列表来识别缺失的区域物种和物体。

  2. 02

    Tri 获得容量后，重新访问悬崖、洞穴和裂缝。将心灵狩猎与区域支线任务和邮票站结合起来，以减少重复旅行。

  3. 03

    结束后，使用可用的完成信息来定位丢失的回声。继续将力量水晶、爱心和印章作为单独的目标进行追踪。

设备、冰沙和挑战

  1. 01

    收集仙女瓶并通过大仙女扩大配件容量。装备适合路线的奖励，而不是将每个位置都保留在战斗效果上。

  2. 02

    当您发现冰沙配方时，记录它们并准备每个区域所需的阻力。一个有用的食谱可以解决环境障碍，而无需新衣服。

  3. 03

    返回沉睡道场，享受更广泛的回声收藏，应对限时挑战。与主要结局分开完成丹佩的自动机请求和可选的迷你游戏奖励。

01

东宫

0 / 3 步骤+

解锁化为壁画并沿墙移动的能力。

攻略路线与谜题解法

  1. 01

    跟随剑运送到庇护所，然后在尤加的攻击后返回家园。借用拉维奥的弓并启动东宫外的配对开关。

  2. 02

    在穿过车道之前观察滚动的巨石。射击远处的开关并乘坐移动平台到达尤加。

  3. 03

    用箭击晕尤加并用剑逼近。获得手镯的墙壁融合能力后，用它沿着你以前无法穿越的壁架逃离地牢。

02

大风之家

0 / 3 步骤+

赢得另一个吊坠。

攻略路线与谜题解法

  1. 01

    恢复奥伦女王的光滑宝石以获得脚蹼，然后租用龙卷风棒。游到大风之屋并在其风控入口处使用钓竿。

  2. 02

    使用向上的阵风和龙卷风棒到达移动平台。融入障碍物周围的墙壁并保持足够的能量来完成每次穿越。

  3. 03

    使用杆上升到 Margomill 的旋转层之上并击中眼睛。在再次尝试到达薄弱点之前，请先移除中间层。

03

赫拉塔

0 / 3 步骤+

完成吊坠。

攻略路线与谜题解法

  1. 01

    从罗索那里获得动力手套并租用锤子。爬上死亡山并压平入口处的钉子。

  2. 02

    用锤子敲击弹簧平台，站在上面等待发射。使用墙壁合并在壁架之间移动，而不会掉到较低的楼层。

  3. 03

    摩尔多姆的尾巴很脆弱；它的头不是。在中心附近战斗并在其后面绕圈，而不是跟随它走向边缘。

04

大师剑和海拉鲁城堡

0 / 3 步骤+

输入洛鲁尔。

攻略路线与谜题解法

  1. 01

    在失落的森林中，遵循鬼魂不断变化的指示，而不是假设每一轮都适用相同的规则。抽出主剑和所有三个吊坠。

  2. 02

    突破城堡屏障，登上尤加。识别副本中的真正目标，并在他离开墙壁时进行攻击。

  3. 03

    沿着新开辟的通道前往洛鲁尔。激活风向标并检查世界裂缝：从不同位置进入裂缝可以提供进入不同区域的通道。

05

盗贼的藏身处

0 / 3 步骤+

释放奥斯法拉。

攻略路线与谜题解法

  1. 01

    进入盗贼镇的藏身处并释放被监禁的盗贼。侦察危险房间时，让她保持安全。

  2. 02

    协调压力开关、移动地板和封锁通道。在小偷等待时融入墙壁以到达控制装置，然后在继续之前返回她。

  3. 03

    当斯塔布林德展示他的盾牌时，融入其中并出现在他身后。营救奥斯法拉后，返回拉维奥获取沙漠宫殿的沙杖。

06

沙漠宫殿

0 / 3 步骤+

营救艾琳。

攻略路线与谜题解法

  1. 01

    使用洛鲁尔的裂缝到达海拉鲁的沙漠。用沙棒升起沙柱，并沿着沙柱的侧面合并以跨越间隙。

  2. 02

    收集泰坦手套并清除阻挡后续路线的大石头。跟踪哪些出口通向外面而不是深入宫殿。

  3. 03

    Boss 位于通往洛鲁尔的路线对面。用沙柱筑起一条通往扎加纳加的道路，避开召唤的敌人，并在触手可及时砍下花朵。

07

黑暗宫殿

0 / 3 步骤+

营救格利。

攻略路线与谜题解法

  1. 01

    潜行绕过宫殿外的守卫，融入墙壁以避免他们的视线。进入前租借炸弹。

  2. 02

    打破木板窗户将光线发送到传感器上。在其他房间，熄灭火把以显露出只有在黑暗中可见的路径。

  3. 03

    轰炸杰马龙王的面具以暴露其弱点。当黑暗掩盖房间时重新点燃房间，然后在躲避其冲锋的同时进行攻击。

08

沼泽宫殿

0 / 3 步骤+

营救奥伦。

攻略路线与谜题解法

  1. 01

    租用钩弓并将大炸弹花带到入口附近的裂缝巨石处。它的爆炸打开了路线并改变了周围的水。

  2. 02

    拉动开关并调节水位以到达不同的壁架。在提高水以改变通道之前，对跨越间隙的目标使用钩射。

  3. 03

    一次将阿古斯的小眼睛拉开并摧毁它们。一旦护盾消失，躲避主体的跳跃并在其落地时进行攻击。

首领战提示

用钩爪拉出阿古斯的小眼睛，摧毁它们并攻击它的身体。

09

骷髅森林

0 / 3 步骤+

营救塞雷斯。

攻略路线与谜题解法

  1. 01

    使用森林的洞作为单独的地牢入口。标记哪个上部开口通向每个下部房间，而不是重复落入同一个分支。

  2. 02

    将眼球移至眼窝，使用墙壁合并和移动平台重新连接路径。一只眼睛无法追踪林克独自走过的每条路线。

  3. 03

    当指关节大师冲锋时，融入墙壁并让它崩溃。在恢复期间出现攻击，然后在下一次尝试之前移动。

10

龟岩

0 / 3 步骤+

营救因帕。

攻略路线与谜题解法

  1. 01

    帮助三只小海龟，让它们与妈妈团聚，到达湖口。带上冰棒。

  2. 02

    冻结熔岩并移动跷跷板平台以创建稳定的交叉口。当冰冻平台无法单独到达出口时，请沿着可进入的墙壁合并。

  3. 03

    通过地板开口将冰块扔到下面的 Grinexx 上。当它浮出水面时，远离它的攻击并攻击暴露的头部。

11

冰之遗迹

0 / 3 步骤+

营救罗索。

攻略路线与谜题解法

  1. 01

    使用可用的火棒到达山上的 Lorule 裂缝。融化入口并拉动中央雕像的舌头来操作电梯。

  2. 02

    将地牢视为受控下降：在下降之前检查洞的着陆位置，融化阻碍的冰并拉动舌头开关将地板移动到位。

  3. 03

    使用重复的火棒攻击来融化达克斯斯塔的外壳。砍掉暴露的生物并在它们冻结之前留下标记的三角形区域。

首领战提示

融化达克斯斯塔的冰衣，砍开它并避开它的三角形冰冻区。

12

洛鲁尔城堡

0 / 3 步骤+

恢复两个王国。

攻略路线与谜题解法

  1. 01

    救出所有七位贤者后，完成洛鲁尔城堡的四项试炼。使用在早期地下城中测试过的工具和墙合并技术。

  2. 02

    对抗尤加加农时，躲避三叉戟的攻击并用剑回击能量齐射。保持移动空间，而不是站在竞技场边缘。

  3. 03

    在墙阶段使用塞尔达的光之弓。从后面射击；在最后一个变体中，沿着墙壁向相反方向开火，这样箭就会绕到尤加的背上。

首领战提示

当你合并时，光之弓会开火。

麦麦和设备改进

  1. 01

    拜访玛玛玛妈妈并开始寻找。聆听呼喊声，利用墙壁合并来驱逐被墙壁束缚的玛伊玛人，并使用升级后的设备重新访问岩石和深水。

  2. 02

    从 Ravio 购买一件物品，然后请 Maiamai 妈妈改进它。租赁无法获得这些永久升级。

  3. 03

    收集四块大师矿石并将其带到相应的铁匠处。分别搜索瓶子位置；空瓶子是永久的奖励，即使里面的东西发生了变化。

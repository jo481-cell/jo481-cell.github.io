01

前三天

0 / 3 步骤+

找回陶笛。

攻略路线与谜题解法

  1. 01

    找到失踪的流浪仙女并将其归还给大仙女。使用 Deku 泡泡弹出气球，完成轰炸机的捉迷藏游戏并记下您自己的密码。

  2. 02

    到达天文台，通过望远镜观察并收集月亮的眼泪。将其交易给商业磨砂以获得钟楼下方的花朵。

  3. 03

    最后一晚的午夜，到达骷髅小子并用泡泡取回陶笛。演奏时间之歌，然后学习治愈之歌并返回大仙女面具。

02

南部沼泽和伍德法尔

0 / 3 步骤+

释放第一个巨人。

攻略路线与谜题解法

  1. 01

    将药物带到神秘森林的小梅，然后乘船游览德久皇宫。沿着猴子的路线，学习觉醒奏鸣曲。

  2. 02

    使用 Deku Link 打开 Woodfall Temple。获得弓，用穿过火焰的箭点燃远处的火把，并使用 Deku 花穿过中央房间。

  3. 03

    在 N64 上对抗奥多瓦，用剑和其他武器创造空当，同时避开召唤的敌人。在 3DS 上，使用 Deku 空中攻击暴露眼睛，然后攻击它。将获救的公主装入瓶子中带回。

03

冬天的山

0 / 3 步骤+

让山区恢复春天。

攻略路线与谜题解法

  1. 01

    带着真理之镜跟随达玛尼并演奏治愈之歌。用温泉水让戈隆长老解冻，然后和他的孩子一起完成摇篮曲。

  2. 02

    在 Snowhead 播放戈隆摇篮曲。获得火焰箭并用它们解冻冰冻的开关；调整中心柱并用戈隆冲头去除其标记部分。

  3. 03

    追随戈特并用戈隆尖刺击中它。在 3DS 中，当它跌倒时攻击它裸露的眼睛。在重置时间之前，将恢复的弹簧用于戈隆种族和剑升级链。

04

一匹马和七个鸡蛋

0 / 3 步骤+

打开大湾寺。

攻略路线与谜题解法

  1. 01

    在周期的早期使用火药桶打开罗马尼牧场，学习艾波娜之歌并到达海岸。治愈米考以获得佐拉面具。

  2. 02

    在海盗堡垒中，获得钩弓并收集四个佐拉蛋。如果您无法携带全部四个瓶子，请在两次旅行之间在海洋研究实验室倒空瓶子。

  3. 03

    在尖峰石找到剩余的三个蛋，利用海马在浑浊的水中航行。将全部七个送到实验室并学习新浪潮 Bossa Nova。

05

大湾机械

0 / 3 步骤+

恢复洋流。

攻略路线与谜题解法

  1. 01

    为露露播放歌曲来唤醒乌龟，并将钩子钩到树上。在寺庙内，沿着彩色管道到达阀门，而不是随意游过中央机械。

  2. 02

    获取冰箭，将其用于冰冻的踏脚石或敌方平台，并反转中央水流以访问剩余的树枝。 3DS 版本限制了冰平台可以形成的位置。

  3. 03

    对抗 Gyorg，保持对安全平台的访问，并在其暴露的弱点时攻击其弱点。在3DS中，后期的水下阶段要求你在Boss吸气时释放水下地雷。

首领战提示

用箭从平台上击晕格奥尔格，用佐拉的电障潜入攻击，然后撤退。

实用提示

一瓶魔法恢复有助于佐拉长时间的战斗。

06

伊卡纳的声音

0 / 3 步骤+

学习空性挽歌。

攻略路线与谜题解法

  1. 01

    从戈尔曼兄弟手中赢得伽罗面具，然后进入伊卡纳。为夏普播放风暴之歌来恢复河流并允许音乐盒屋序列。

  2. 02

    在不吓跑帕梅拉的父亲的情况下找到她，并为吉布多面具演奏治愈之歌。将其穿在地下并带上吉布多斯人要求的补给品。

  3. 03

    收集镜盾，使用伊卡纳城堡的反射光，并将王座室暴露在阳光下。击败国王和他的守卫，然后学习空之挽歌。

07

倒立的塔

0 / 3 步骤+

释放第四个巨人。

攻略路线与谜题解法

  1. 01

    使用不同形式的挽歌在塔楼的开关上留下雕像。在里面，收集光箭，然后尝试翻转地牢。

  2. 02

    用光箭射出外面的红色徽章。重新审视倒置的房间，记住天花板会成为路线，宝藏位置也会随着你的变化而变化。

  3. 03

    收集两个方向的所有十五个流浪仙女，然后将其归还。 Twinmold 在 N64 和 3DS 中使用巨人面具的方式不同；在 3DS 中，在巨型阶段可用之前击败第一个蠕虫。

08

最后一晚

0 / 3 步骤+

停止坠落的月亮。

攻略路线与谜题解法

  1. 01

    最后一晚的午夜，将四名首领遗骸运送到钟楼。玩命令誓言来阻止月球并进入它。

  2. 02

    在接近树下的孩子之前，完成孩子们的可选试验。带齐全部二十个非变身面具即可获得烈神面具。

  3. 03

    攻击马吉拉面具的背面或在适当的时候反射其光束。小心地跟随移动的化身，然后使用远程眩晕和剑开口来对抗挥舞鞭子的最终形态。

三天完成计划

  1. 01

    将永久奖励与时间之歌重置的事件分开。在倒带之前存入卢比并返回地牢流浪仙女；暂时的仙女不会延续。

    为安居和卡菲预留一辆专用自行车。保持笔记本的预约有序，并使用单独的周期来获得互斥的交付奖励。

  3. 03

    将区域心脏和面具任务与适当的变形结合起来，然后使用月球试验来获得最终的心脏。检查您版本的瓶子列表，因为重制版添加了另一个瓶子。

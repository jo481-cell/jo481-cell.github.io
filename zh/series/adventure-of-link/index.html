01

帕拉帕宫

0 / 3 步骤+

照亮第一座宫殿之外的道路。

攻略路线与谜题解法

  1. 01

    在劳鲁学习盾牌并在进入帕拉帕宫之前在路上收集经验。护盾可以减少伤害，但会使用其他法术所需的魔法。

  2. 02

    在放置水晶之前，探索宫殿的侧枝寻找蜡烛。蜡烛照亮了后来使用的主世界洞穴。

  3. 03

    对着马头，跳跃并攻击盔甲上方的马头，然后随着狼牙棒的挥动而撤退。获胜后继续前往雕像并放置水晶。

02

城镇和死亡山

0 / 3 步骤+

找回锤子。

攻略路线与谜题解法

  1. 01

    将偷来的奖杯归还给鲁托，让他学习跳跃。在萨利亚找到女人的镜子以获得生命，然后使用巴古的许可过河。

  2. 02

    在死亡山中，记录洞穴入口和出口，而不是随机选择每个岔路口。在到达 Hammer 的最后一段路程之前重新填充。

  3. 03

    使用锤子打破主世界的岩石并到达附近的魔法容器。在米多，通过医药任务获得仙女并使用跳跃到达向下推力老师。

03

绿宫

0 / 3 步骤+

穿过易碎的石头。

攻略路线与谜题解法

  1. 01

    使用锤子到达沼泽宫殿。携带足够的魔法来保护盾牌和生命，并检查较低的树枝以获取便利手套。

  2. 02

    手套允许剑击破坏地牢方块。带着它返回堵塞的走廊，而不是浪费时间寻找单独的开关。

  3. 03

    随着战斗的进行，头盔头的头盔会脱落并发射射弹。跳起来攻击脆弱的头部，然后远离漂浮的头盔。

进度检查点

首领战提示

攻击赫尔梅特黑德的头部，然后攻击裸露的身体；避免浮头。

实用提示

绕道获取经验比反复失去几乎完成的关卡更安全。

04

岛宫酒店

0 / 3 步骤+

到达海拉鲁东部。

攻略路线与谜题解法

  1. 01

    从海岸通过洞穴路线到达岛屿。在继续寻找 Boss 之前先在宫殿内寻找木筏。

  2. 02

    对正面接近有危险的敌人使用向下推力。当通道或间隙需要飞行时，请为仙女保留魔法。

  3. 03

    雷博纳克首先骑马进攻。使用向下的攻击将他打倒，然后通过在盾牌周围交替进行高低攻击来对抗暴露的铁指节。

进度检查点

首领战提示

向下冲到雷博纳克的马上，然后与他下马的形态战斗。

实用提示

仙女形态可以绕过狭窄的通道，但无法正常战斗。

05

迷宫宫

0 / 3 步骤+

取得靴子并学会反射魔法。

攻略路线与谜题解法

  1. 01

    在海拉鲁东部，帮助纳布鲁的女人获得火力。到达达鲁尼亚，从迷宫岛救出孩子并返回反射；也可以从隐藏的老师那里学习向上推力。

  2. 02

    在迷宫宫殿中找回靴子。它们可以让你穿越主世界上指定的浅水路径，而不是每一个海区。

  3. 03

    卡洛克无法被普通的剑攻击击败。施放反射，面对他的射弹并蹲下，用盾牌对着他们。

06

海洋皇宫

0 / 3 步骤+

获取长笛。

攻略路线与谜题解法

  1. 01

    使用靴子寻找穿越东海的路线。在放置下一个水晶之前在宫殿中寻找长笛。

  2. 02

    如果你的生命或魔法很低，不要追逐每一个可选的经验包。保留足够的魔力用于 Boss 期间的防御和治疗。

  3. 03

    古玛挥舞着重型武器，同时在攻击之间让他的身体暴露在外。上前一步迎接剑击，然后在剑击中你之前后退。

07

隐秘宫殿

0 / 3 步骤+

放置第六个水晶。

攻略路线与谜题解法

  1. 01

    吹奏笛子消除河魔。在新卡苏托，获得最终的魔法容器和咒语，然后在城镇的空旷地方使用咒语来揭示魔法钥匙。

  2. 02

    在三岩层吹笛，揭开隐宫。取回十字架并注意看不见的地板缝隙；一些故意的跌倒会导致新的路线。

  3. 03

    在下降过程中为Jump和Fairy保留魔法。对抗巴尔巴，当龙从熔岩中出现时，跳跃并攻击它的头部，然后返回安全地面。

首领战提示

当巴尔巴的头部上升时，使用跳跃和向下的推力；避开熔岩。

08

大皇宫

0 / 3 步骤+

领取勇气三角神力。

攻略路线与谜题解法

  1. 01

    确认所有六个水晶都已放置并收集每个魔法容器。在老卡苏托学习雷霆，然后在前往大皇宫的漫长道路之前补充能量。

  2. 02

    这座宫殿既是一次航行挑战，也是一次战斗考验。标记电梯分支并避免在最后的房间之前花费所有魔法。

  3. 03

    施放雷霆以暴露雷鸟的弱点，然后跳跃攻击其脸部。黑暗林克立即跟进：格挡、改变攻击高度并控制开口，而不是不断跳跃。

进度检查点

首领战提示

施放雷电魔法，使雷鸟露出面部弱点。对付暗影林克时，用高低剑击寻找破绽，不要浪费攻击魔法。

实用提示

这座宫殿内的游戏结束后可以在其入口处重新开始。

心、魔法和技术

  1. 01

    收集所有四个额外的心之容器和所有四个魔法容器。魔法能力是一个进步要求，因为最终的法术取决于它。

  2. 02

    查看大殿前的法术列表和两套剑法。攻击、魔法、生命各可达8级；提高它们会使最终路线更加宽容。

  3. 03

    保存一次性的额外生命玩偶以供游戏后期困难的尝试，而不是在经过时自动收集它们。

01

天空和封闭的森林

0 / 3 步骤+

找到塞尔达走过的路线。

攻略路线与谜题解法

  1. 01

    找到失踪的阁楼翼，练习飞行并完成翅膀仪式。晚上跟随Fi前往女神之剑并放置牌位。

  2. 02

    下降到密封之地并进入法隆森林。寻找失踪的基奎斯，然后使用弹弓放下悬挂的藤蔓。

  3. 03

    使用绳索和藤蔓路线穿越深林。敲击天观寺入口上方的水晶即可打开门。

02

天观寺

0 / 3 步骤+

抵达泉水。

攻略路线与谜题解法

  1. 01

    让眼哨兵跟随圆形剑运动，直到他们感到头晕。当需要多只眼睛同时注视刀片时，请调整您的位置。

  2. 02

    获得甲虫并让它飞过小开口来敲击开关。将水升到上方通道并旋转雕刻钥匙以适合首领门。

  3. 03

    对抗吉拉希姆的护手，将剑握在一侧，然后从另一个方向砍击。将你的斩击与他即将到来的匕首的方向相匹配。

03

埃尔丁与地神庙

0 / 3 步骤+

按照第二块平板电脑进行操作。

攻略路线与谜题解法

  1. 01

    帮助莫格玛并获得挖掘手套。搜索标记的埃尔丁区域，寻找所有入口钥匙，使用炸弹清除封锁的路线。

  2. 02

    在寺庙内，收集炸弹袋并将大石球滚过熔岩。在破裂的墙壁上使用炸弹来延长球的路线。

  3. 03

    跑上坡以避免斯卡拉德拉滚动的身体。当它吸气时，将炸弹扔进它的嘴里，爆炸后割伤裸露的眼睛。

04

记忆中的沙漠

0 / 3 步骤+

到达时间神殿。

攻略路线与谜题解法

  1. 01

    激活时移石来恢复其半径内的机械。使用地图沿着流沙下方的安全地面行驶，并为三个开放节点供电。

  2. 02

    收集采矿设施中的风箱。清除平台和开关上的沙子，并使用空气来移动风力机械装置。

  3. 03

    从毫无防备的角度切掉莫达拉克的爪眼。一旦爪子消失，就刺入中央的眼睛；当 Boss 挖洞时，使用风箱将其揭开。

05

神圣的火焰

0 / 3 步骤+

开始淬炼剑。

攻略路线与谜题解法

  1. 01

    击退被囚禁者并学习女神歌谣。用 Scrapper 恢复掉落的风车部分，并将 Skyloft 的风车对准灯塔。

  2. 02

    进入雷霆头并到达歌之岛。在法隆的寂静国度中，收集眼泪，同时管理守护者的唤醒计时器并避开警报水。

  3. 03

    使用水龙鳞片到达弗洛里亚湖。返回天景获取圣水并将其交给水龙以打开瀑布。

06

古代蓄水池

0 / 3 步骤+

用法罗尔的火焰淬火剑。

攻略路线与谜题解法

  1. 01

    阅读雕像的方向线索并在锁着的门处重现序列。探索上层寺庙及其较暗的下层，作为一条路线的连接部分。

  2. 02

    获得鞭子来拉动把手并从敌人那里偷走钥匙。升起中央雕像，然后通过打开的通道返回到 Boss 处。

  3. 03

    用鞭子将克洛克托斯的手臂拉开。拿起它掉落的一把剑，打破腿部和胸部的保护，然后攻击里面的心脏。

07

被埋没的海

0 / 3 步骤+

找到奈鲁的火焰。

攻略路线与谜题解法

  1. 01

    为爪射完成奈鲁的寂静国度。帮助船长穿过他的家、造船厂和海盗据点，然后找到海上隐形船的位置。

  2. 02

    获得弓并通过开口射击桅杆的时移石，以在时代之间切换船舶。释放船员并到达与发动机相关的通道。

  3. 03

    使用 Skyward Strikes 切断 Tentalus 的触手，然后在它倒下时射击它的眼睛并进行砍击。在上阶段，剪掉攻击头发并重复睁眼。

08

丁的火焰

0 / 3 步骤+

完成剑的转变。

攻略路线与谜题解法

  1. 01

    完成丁的寂静领域，获得火盾耳环。帮助刮刀将水龙盆带到山顶，扑灭入口处的火焰。

  2. 02

    使用充满水的植物暂时冷却熔岩。获得莫格玛手套并在地下挖掘隧道来操作开关并追赶挖洞的敌人。

  3. 03

    对抗吉拉希姆时，寻找他双手未防守的剑角。避免他的落地攻击，然后惩罚他的恢复，而不是攻击封闭的后卫。

09

英雄之歌

0 / 3 步骤+

赢得最终审判。

攻略路线与谜题解法

  1. 01

    打开时间之门并接受塞尔达的祝福。帮助雷霆头的利维亚斯，然后寻找英雄之歌中三龙的部分。

  2. 02

    在法隆，一边观察空气，一边收集塔德通人。在埃尔丁，在接近巨龙之前通过潜行路线取回被没收的装备。

  3. 03

    对于Lanayru，将生命树幼苗带到封印神殿的过去，然后在现在收集长出的果实。在最初的 Wii 版本中，请在 Lanayru 之前完成 Faron 和 Eldin，以避免记录的英雄之歌进度问题。

10

天空要塞和最后的下降

0 / 3 步骤+

完成跨越时空的任务。

攻略路线与谜题解法

  1. 01

    完成天空阁楼的寂静国度并使用试炼之石打开天空要塞。重新布置其房间以连接三个 Triforce 目标。

  2. 02

    跟随吉拉希姆回到过去并与军队作战。在最后的吉拉希姆决斗中，将他逼向边缘，完成平台阶段并用匹配的切口折断他的大剑。

  3. 03

    对抗死亡时，反击剑攻击，但不要过度伸展。当闪电开始时，举起剑刃蓄力，击晕他，并在他倒下时给予最后一击。

心、感恩水晶和天空奖励

  1. 01

    完成 Skyloft 的角色任务并在夜间寻找松散的感恩水晶。在每个奖励阈值处返回 Batreaux。

  2. 02

    被击中的女神方块会打开天空其他地方的箱子。分两步跟踪立方体和宝箱，这样激活的立方体就不会被误认为是收集的奖励。

  3. 03

    通过游泳、爪射和改进的挖掘重新审视地表区域。在可选的耐力挑战之前完成瓶子、心脏碎片和设备升级。

01

灵魂的坟墓

0 / 3 步骤+

拯救马库树的未来。

攻略路线与谜题解法

  1. 01

    维兰（Veran）占有奈鲁（Nayru）后，拿起剑并跟随马库树（Maku Tree）的消失回到过去。营救小树，然后返回现在的墓地路线。

  2. 02

    在灵魂之墓中，点燃火把并调查可移动的方块。动力手链打开了穿过之前无法举起的罐子的路线。

  3. 03

    摧毁南瓜头的身体，举起南瓜并扔掉。在小精灵恢复保护之前对其进行攻击。

02

翼地牢

0 / 3 步骤+

获得大鹏的羽毛。

攻略路线与谜题解法

  1. 01

    从奈鲁家里拿走时代竖琴。当现在的入口倒塌时，使用时间旅行到达过去的翼地牢。

  2. 02

    获得大鹏的羽毛并将其用于侧视通道和间隙。对于彩色地板谜题，请规划一条到达每个所需图块且不捕获移动标记的路线。

  3. 03

    从上面的平台向 Head Thwomp 的开放顶部投掷炸弹。由此产生的面决定了它的响应；继续移动并重复，直到破坏性的红色结果击败它。

03

月牙岛和月光石窟

0 / 3 步骤+

恢复你的设备和种子射手。

攻略路线与谜题解法

  1. 01

    沉船后，通过Tokay交易所找回被盗的设备。在过去种下香苗，这样它的树就存在于现在。

  2. 02

    在月光石窟中，打破控制中央路线的水晶并取回种子射手。当直接射击无法到达开关时，请斜向瞄准。

  3. 03

    暗影女巫被看见后就退缩了。转身，然后从墙上弹起一粒种子，这样当她从后面接近时种子就会击中她。

04

骷髅地牢

0 / 3 步骤+

取得换位钩爪，熟悉它的用法。

攻略路线与谜题解法

  1. 01

    完成对称城市的修复并利用竖琴的扩展时间旅行到达高地。过去所做的改变改变了现在的路线。

  2. 02

    收集开关钩并与罐子或菱形物体交换位置。在间隙的每一侧保留一个有用的物体，以便您可以返回。

  3. 03

    在离开起始方块之前，先规划好长长的地板着色拼图。对抗Eyesoar，将中央之眼从其护卫中钩出来，并在眩晕时攻击它。

05

滚动山脊和皇冠地牢

0 / 3 步骤+

获得索马利亚之杖。

攻略路线与谜题解法

  1. 01

    带上炸弹花来释放戈隆长老。沿着山脊通道走，注意哪些入口属于每个时代。

  2. 02

    索马里的手杖为压力开关和路径谜题创造了一个方块。将其放置在穿过依赖于按下开关的路线之前。

  3. 03

    烟雾的碎片会跟随障碍物。添加或移除甘蔗块以将它们重定向到彼此，然后敲击重新组装的云并重复下一个图案。

06

美人鱼的洞穴

0 / 3 步骤+

完成一个跨越两个时代的地下城。

攻略路线与谜题解法

  1. 01

    完成戈隆交易、舞蹈和迷你游戏链，以获得两个时代的钥匙。美人鱼的洞穴是一个分布在两个版本的地牢中的进程。

  2. 02

    打开过去的必经之路，然后重温现在。一旦你拥有了美人鱼套装，就可以潜入深水房间并检查水下出口。

  3. 03

    对着八角形红色一侧的小嘴使用种子发射器。潜入水中时，跟随水下并用剑攻击；当平台重新浮出水面时返回平台。

07

奈鲁和贾布-贾布

0 / 3 步骤+

扩展时间旅行并升级钩子。

攻略路线与谜题解法

  1. 01

    趁她不在的时候进入安比的宫殿。对被附身的奈鲁使用神秘种子，用开关钩将维兰拉开并攻击维兰而不是奈鲁。

  2. 02

    借助万古之音，帮助佐拉国王解决被污染的海洋。进入 Jabu-Jabu 并使用水位开关来暴露不同的楼层。

  3. 03

    升级到长钩并重新审视长距离。对抗等离子战士，等待它的射弹，然后交换位置，这样 Boss 就会改变颜色并被相反颜色的子弹击中。

08

古墓

0 / 3 步骤+

收集最后的精华。

攻略路线与谜题解法

  1. 01

    使用佐拉天平到达海盗路线并获取不归之海所需的信息。坟墓的入口属于过去。

  2. 02

    找到能量手套并收集四块石板。将它们安装到中央路线以打开更深的房间，而不是单独寻找普通的首领钥匙。

  3. 03

    Ramrock 在每个阶段都会更换工具：收回拳头，将炸弹放入杯状手中，将种子弹到盾牌后面，然后用动力手套拉回一个球并将其释放。

首领战提示

返回拳头，轰炸杯状手，将种子弹到其守卫后面，然后在其球手上使用手套。

实用提示

Ramrock 在不同阶段之间更改所需的工具。

09

黑塔

0 / 3 步骤+

免费的实验室。

攻略路线与谜题解法

  1. 01

    收集全部八种精华后，获得巨大的玛库种子。进入过去的黑塔，沿着视觉迷宫线索到达其上层房间。

  2. 02

    使用神秘种子和长钩将维兰与安比分开，然后攻击暴露的灵魂。击败飞行阶段，同时避开镜子移动的阴影。

  3. 03

    在最后的变身中，轰炸蜘蛛以暴露其脸部，躲避跳跃的装甲形态并攻击其暴露的头部，并在蜜蜂形态接近时对其进行攻击。

首领战提示

用神秘种子和长钩分离维兰。轰炸蜘蛛，攻击乌龟裸露的头部，并在可以到达时攻击飞行形态。

实用提示

连动结局和秘密交换

  1. 01

    先通关其中一作，再用通关密码开始另一作。将每个额外的密码和接收它的角色姓名一起记录下来，并按要求把奖励密码交给法罗。

  2. 02

    在链接故事的额外救援事件和最终地牢之后，继续前往仪式室。将女巫的魔法反射到对面的姐妹身上，然后使用元素种子和剑孔对抗组合形态。

  3. 03

    加农的最后一场遭遇是在女巫们的带领下进行的。观察传送模式，远离三叉戟的射程，并在他再次出现时使用蓄力剑攻击。相连的结局与单独击败维兰不同。

  1. 01

    在两个时代中寻找心灵奖励，并带着铲子、游泳装备和升级的鱼钩返回。记录一个位置属于哪个时代。

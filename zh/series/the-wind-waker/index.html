起点和被遗忘的堡垒

0 / 3 步骤+

尝试营救艾瑞尔。

攻略路线与谜题解法

  1. 01

    向逆戟鲸学习剑术，在森林中营救泰特拉并登上海盗船。在堡垒中，在穿过暴露的人行道之前关闭探照灯。

  2. 02

    在手无寸铁的情况下，使用桶并仔细把握时机来通过守卫。在通往艾瑞尔的上方通道附近取回剑。

  3. 03

    到达风车岛（Windfall Island）后，取得船帆并救出廷格尔。回到红狮子王身边，向东航行至龙之岛（Dragon Roost Island）。

02

第一颗珍珠

0 / 3 步骤+

帮助龙栖息处的 Rito。

攻略路线与谜题解法

  1. 01

    学会风之歌，与利特族交谈并帮助梅德利登上高处的平台。用水浇活枯萎的炸弹花，再用它们打开通往洞穴的道路。

  2. 02

    在洞窟内，用水罐冷却熔岩，并用炸弹炸开被堵住的通道。救出梅德利以获得抓钩，再借助抓钩荡过较宽的沟壑。

  3. 03

    将瓦鲁的尾巴钩在戈玛上方，将天花板拉到它的壳上。一旦外壳破裂，拉动或接近暴露的眼睛并进行攻击。

03

禁林

0 / 3 步骤+

为法罗尔之珠营救马卡。

攻略路线与谜题解法

  1. 01

    清除大德库树上的生物并使用巴巴芽攀爬。获得德库叶，乘风向禁林滑翔。

  2. 02

    使用叶子操作风力装置并移动悬挂平台。用回旋镖砍断藤蔓，在释放回旋镖之前标记几个目标。

  3. 03

    用回旋镖砍断卡勒·德莫斯的支撑藤蔓。跑进落花中攻击它的核心，然后在它关闭之前离开。

04

三颗珍珠和沉没的王国

0 / 3 步骤+

拔出大师剑。

攻略路线与谜题解法

  1. 01

    沿着大鱼岛的线索回到风车岛并从海盗那里获取炸弹。返回起点并炸开漩涡屏障与贾本会面。

  2. 02

    将三颗珍珠放在相应的三角岛上。在众神之塔中，利用不断变化的水位来导航较低的房间。

  3. 03

    用命令旋律引导雕像并获得弓。射击戈丹的手和眼睛，然后将炸弹扔进它的嘴里；随后下降并拔出大师剑。

05

返回要塞

0 / 3 步骤+

营救艾瑞尔并发现这把剑的弱点。

攻略路线与谜题解法

  1. 01

    带着大师剑和炸弹返回堡垒。通过归还幻影加农的能量球来击败他，然后收集骷髅锤。

  2. 02

    使用锤子敲击阻塞救援路线的钉子。爬上洪水塔并继续前进，直到到达屋顶竞技场。

  3. 03

    当赫尔玛洛克之王将它的喙插入地板时，用锤子敲击它。打破它的面具后，用剑攻击暴露的头部。

06

大地圣人

0 / 3 步骤+

恢复前半部分剑力。

攻略路线与谜题解法

  1. 01

    学习烈风之歌并获得火与冰箭。冻结火山，收集能量手镯并打开地坛的石头入口。

  2. 02

    学习大地神的歌词并与 Medli 一起演奏。在里面，使用命令旋律瞄准她的反射光，同时林克操作开关并携带镜子。

  3. 03

    获取镜盾并组合光束以移除光敏障碍。照亮贾哈拉，把他举起并扔到柱子上，然后击败四散的坡斯。

07

风圣

0 / 3 步骤+

完成恢复大师剑。

攻略路线与谜题解法

  1. 01

    使用火焰箭解冻冰环岛的入口并取回铁靴子。学习风神的咏叹调并在森林天堂的瀑布后面找到玛卡。

  2. 02

    使用命令旋律引导马卡前往种植点。当同伴分开时，使用弹簧装置上的铁靴和钩弓重新连接路线。

  3. 03

    钩住莫尔盖拉裸露的舌头并用剑击打它。继续在坚硬的沙子上移动，并在较小的蠕虫干扰你的目标时清除它们。

08

八块勇气

0 / 3 步骤+

重新开放通往海拉鲁的路线。

攻略路线与谜题解法

  1. 01

    获取 IN-credible 海图并浏览八个 Triforce 地点。在出发进行全海收集之旅之前，准备好所需的设备和卢比。

  2. 02

    在 GameCube 上，将每个 三角神力海图 带到 Tingle 进行破译，然后再抢救其碎片。 HD中直接收集五个碎片，只破译剩下的三个海图。

  3. 03

    使用正确的海图和海方将船对准打捞灯。八块碎片全部集齐后，返回众神之塔。

09

加农塔

0 / 3 步骤+

为海洋之旅画上圆满的句号。

攻略路线与谜题解法

  1. 01

    返回海拉鲁并穿过修复后的路线到达加农之塔。完成记住的头目房间并沿着塔楼的视觉线索穿过迷宫。

  2. 02

    对幻影加农使用光箭，并在射击尾部宝石之前切断傀儡加农的绳子。观察尾巴在其后期形态中的位置。

  3. 03

    在最后的决斗中，用塞尔达的箭创造空缺。当战局发生变化时，用盾牌反射她的箭，击晕加农多夫，然后顺着剑口走。

海图、心形和升级

  1. 01

    在每个海域喂鱼人以构建海图。将附近的岛屿、Great Fairies、Big Octos 和打捞地点合并在一条航行路线中。

    将寻找藏宝图与抢救其奖励分开。在计算收集到的相关红心或卢比之前，标记两个阶段。

  3. 03

    挑战较长的支线任务前，先收集空瓶和容量升级。请选择正在游玩的版本，因为HD版改动了部分海图和奖励。

版本差异说明

GameCube 使用八个解密的 Triforce 海图； Wii U HD 将其中五个海图奖励直接替换为碎片。 HD 还改变了航行便利性和一些收集要求。

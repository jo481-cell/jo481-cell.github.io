01

了解共享控件

0 / 3 步骤+

使党同心协力。

攻略路线与谜题解法

  1. 01

    在开始计分阶段之前，练习携带和投掷搭档。就谁留在开关上以及谁先过马路达成一致。

  2. 02

    进入新谜题时检查可用的物品基座。给每个玩家一个明确的角色，而不是让每个人一次交换装备。

  3. 03

    在离开房间之前，找回失散的伙伴并检查可以获得的奖励。协调退出比单独前进更安全。

02

树海

0 / 3 步骤+

获得森林的第一把钥匙。

攻略路线与谜题解法

  1. 01

    探索森林的树枝并检查地面，然后冲过砍伐的植被。一边收集散落的卢比，一边保留返回派对的路线。

  2. 02

    使用提供的工具在独立平台之间移动并一起操作配对机制。

  3. 03

    用相配的彩色林克敲击大曼德拉的花蕾。当杠杆出现时，将它们拉到一起以暴露下一个目标。

03

距骨洞

0 / 3 步骤+

完成冰雪挑战。

攻略路线与谜题解法

  1. 01

    缓慢接近冰冷的角落，并在到达边缘之前抵抗滑行。不要将队友扔到接球玩家未检查过的平台上。

  2. 02

    保留飞马鞋以备遇到 Boss 时使用，并在奔跑前将每次冲锋排好队。

  3. 03

    将德拉佐尔撞向冰墙，然后在冰冻状态下砍它。后期协调玩家可见的颜色信息。

04

死亡之山

0 / 3 步骤+

领取第三把开门钥匙。

攻略路线与谜题解法

  1. 01

    等待熔岩危险完成其循环后再穿越。玩家之间留出足够的空间，这样一个错误就不会导致整个队伍陷入危险。

  2. 02

    将远程切换任务分配给工具可以安全到达的玩家，然后在 Boss 面前重新集结。

  3. 03

    返回 Gouen 的射弹，并使用与其当前颜色相匹配的林克。当 Boss 化为火焰后，找到并攻击其脆弱的身体。

首领战提示

将 Gouen 的彩色射弹与匹配的 Link 一起归还；击打分散的火焰，露出它的身体并完成较小的形态。

实用提示

等待安全着陆，而不是冲过熔岩。

05

打开瓦蒂宫殿

0 / 3 步骤+

将三场胜利转化为最终路线。

攻略路线与谜题解法

  1. 01

    完成树海、塔洛斯洞和死亡山即可获得初始钥匙套装。在选择瓦蒂宫殿之前查看阶段选择屏幕。

  2. 02

    对于更高的关键级别，请重玩具有所需卢比目标的区域。高效的收集比赢得与队友的比赛更重要。

  3. 03

    在开始宫殿路线之前检查每个参与玩家的访问权限。不同的按键设置会带来不同的挑战。

06

穿过宫殿

0 / 3 步骤+

一起到达风系魔法师。

攻略路线与谜题解法

  1. 01

    将每个房间视为一个合作谜题：识别出口、保持出口打开的开关以及连接它们所需的工具。

  2. 02

    利用斗篷的预期间隙并控制风扇周围的运动。避免让每个玩家同时陷入倒塌的地板上。

  3. 03

    在开始瓦蒂之前恢复生命值并选择竞技场的装备。将团队的协调保留到颜色相关的阶段。

07

瓦蒂和救援

0 / 3 步骤+

释放塞尔达并完成第一个任务。

攻略路线与谜题解法

  1. 01

    将炸弹投进瓦蒂的龙卷风并在他附近引爆。重复直到他落入剑的射程内。

  2. 02

    在后面的战斗中，在匹配的林克之间传递变色弹丸以造成眩晕。

  3. 03

    读取暴露的手臂目标显示的颜色并协调相应侧面的攻击。不要假设每个射弹都遵循相同的颜色规则。

首领战提示

定时炸弹在龙卷风内的瓦蒂旁边爆炸。在颜色阶段，对射弹和暴露的彩色目标使用匹配的林克。

实用提示

调出弹丸当前的颜色；截击可以改变所需的球员。

版本差异说明

原版《四剑》需要多人游戏；周年纪念版增加了单独控制和奖励区域。阶段选择不同的房间布局，因此该路线侧重于工具、合作和首领规则，而不是发明固定的房间顺序。

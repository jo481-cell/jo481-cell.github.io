1993 · Game Boy

塞尔达传说：织梦岛

八件乐器，一座不可能的岛屿。每一个新的运动工具都为Koholint开辟了另一条道路——以及关于梦想的另一个问题。

出发之前

您的旅程，按照您的节奏。

以1993年Game Boy版主线为基础。DX版新增了可选的服装迷宫。2019年Nintendo Switch版调整了操作，并加入镶嵌迷宫；本攻略不要求完成这些额外内容。

  • 在 Game Boy 上，为 A 和 B 分配工具；剑和盾不是永久映射的。
  • 继续放大镜的交易序列；在结局之前购买弓。
  • 向马林学习《风鱼歌谣》。

01

尾洞

0 / 3 步骤+

找到第一个乐器。

攻略路线与谜题解法

  1. 01

    从塔林手中夺走盾牌，并在海滩上夺回剑。在森林里，将蘑菇带给女巫，然后对浣熊使用她的魔法粉，打开通往尾钥匙的路线。

  2. 02

    在尾洞内，收集大鹏的羽毛并用它来跨越地板间隙。在收集钥匙之前，匹配旋转敌人身上的符号。

  3. 03

    摩尔多姆的弱点是它的尾巴。靠近平台中间并在其后面绕圈；跌倒会让你离开竞技场。

02

瓶子石窟

0 / 3 步骤+

解除岛上的障碍。

攻略路线与谜题解法

  1. 01

    莫布林袭击后，从洞穴中救出鲍哇并将他带到戈彭加沼泽。他吃掉了堵塞瓶子洞的花。

  2. 02

    点燃入口火把并取回动力手镯。对于 Pols Voice 谜题，首先击败兔子般的敌人，其次击败蝙蝠，最后击败斯塔福斯。

  3. 03

    阻挡精灵的火球，击打瓶子直到它停止，然后用手镯举起并扔出它。一旦它破裂，攻击暴露的精灵。

03

关键洞穴

0 / 3 步骤+

获得飞马靴子。

攻略路线与谜题解法

  1. 01

    在卡纳莱特城堡完成理查德对五片金叶的要求，然后穿过他别墅后面的田野挖出史莱姆钥匙。

  2. 02

    在钥匙洞穴内，收集飞马靴子并结合奔跑与大鹏之羽来清除更长的间隙。在离开之前击败可疑房间中的所有敌人。

  3. 03

    冲入史莱姆眼使其掉落，然后攻击并穿过其两半之间的连接处。当分开的眼睛落地时跳跃以避免被击晕。

04

钓鱼者的隧道

0 / 3 步骤+

学习游泳。

攻略路线与谜题解法

  1. 01

    带马林去唤醒封锁亚纳沙漠的海象。击败兰莫拉获得钓鱼者钥匙，解锁瀑布并从上面的山路进入。

  2. 02

    了解线索室中发光地砖的顺序，然后在匹配的谜题室中重复该顺序。获得脚蹼来探索深水。

  3. 03

    琵琶鱼在水下战斗。游到它的头部附近，击中发光的诱饵，远离掉落的碎片和较小的鱼。

05

鲶鱼的胃

0 / 3 步骤+

恢复钩爪。

攻略路线与谜题解法

  1. 01

    帮助鬼魂回到它的房子和坟墓，然后通过水下通道潜入玛莎湾的入口。

  2. 02

    追踪斯塔福斯大师的重复遭遇，直到你恢复钩射。攻击骷髅使其倒塌，并在其倒下时使用炸弹。

  3. 03

    对于史莱姆鳗，用钩箭从墙壁开口中拉出真正的头。攻击它暴露的身体，同时避开中心旋转的尾巴。

06

面神社

0 / 3 步骤+

举起较重的雕像。

攻略路线与谜题解法

  1. 01

    在打开面孔神社之前，参观南部神社以获得面孔钥匙和壁画。带上炸弹，准备举起巨大的大象雕像。

  2. 02

    获得更强大的能量手镯并将雕像扔到密封的门上。对于棋子拼图，要考虑落地运动而不是盲目投掷。

  3. 03

    当门面的脸出现在地板上时，在上面放置一枚炸弹。继续在临时洞周围移动；当洞打开时，避免站在洞旁边。

07

鹰塔

0 / 3 步骤+

把上层楼拆下来。

攻略路线与谜题解法

  1. 01

    学习青蛙的灵魂之歌，复活飞翔的公鸡并用它到达鸟钥匙。沿着山洞前往鹰塔。

  2. 02

    携带铁球穿过塔楼并将其扔进所有四根柱子中。在将球抛在后面之前计划如何将球移过障碍物；摧毁柱子会降低上层的高度。

  3. 03

    在爬向邪鹰之前收集镜盾。将其举起，顶着羽毛，迎风行走，停留在平台上，然后在老鹰飞过时击中其喙。

08

龟岩

0 / 3 步骤+

拿第八件乐器来说。

攻略路线与谜题解法

  1. 01

    使用镜盾穿过火焰喷射器洞穴。在龟岩外演奏青蛙灵魂之歌，击败觉醒的入口守护者并进入。

  2. 02

    操纵移动平台来填补地板拼图中的每个间隙。收集魔法棒，然后用它来融化冰块，同时保留作为踏脚石所需的方块。

  3. 03

    当热头从熔岩中出现时，用魔法棒射击它。一旦外壳破裂，继续向暴露的核心开火。

09

风鱼的蛋

0 / 3 步骤+

遵循你自己的迷宫线索。

攻略路线与谜题解法

  1. 01

    完成交易序列即可获得放大镜。阅读以前无法阅读的图书馆书籍，并从您自己的保存中记录迷宫方向。

  2. 02

    用全部八种乐器演奏蛋外的风鱼歌。按照您在里面记录的指示进行操作；其他玩家的序列可能不匹配。

  3. 03

    更改梦魇形态的工具：为斑点使用魔法粉末，为巫师使用反射射弹，为熟悉的怪物使用剑攻击，为最后一只眼睛使用箭或回旋镖。

本章参考资料

进度检查点

首领战提示

对黏液形态撒魔法粉，弹回魔法弹，并用剑攻击可伤害的形态；最后跳过旋转的手臂，射击睁开的眼睛。

实用提示

使用游戏中的线索而不是记住的迷宫路线。

贸易、贝壳和心

  1. 01

    每当您进入新的结算时，都会推进交易链。它最终提供了读取蛋的路线并获得回旋镖所需的放大镜。

  2. 02

    获得铲子、手镯、脚蹼和钩箭后，重游海滩、城堡、草原和山洞。在您的版本的参考中标记各个贝壳和心脏位置。

  3. 03

    在原版和 DX 版本中，在收集更多贝壳之前，请在达到 5 个和 10 个贝壳里程碑时访问贝壳大厦； Switch 使用不同的奖励阶梯。

版本差异说明

Game Boy、DX 和 Switch 的收藏总数不同。 DX添加了彩色地下城和照片； Switch 有密室地下城、瓶子和五十个贝壳。在跟踪完成情况之前使用版本选择器。

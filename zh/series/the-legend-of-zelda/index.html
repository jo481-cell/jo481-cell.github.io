01

剑与鹰

0 / 3 步骤+

领取第一个三角神力碎片。

攻略路线与谜题解法

  1. 01

    从起始屏幕开始，在洞穴中收集剑。向右走一次，向北走四个屏幕，然后向左走一次，找到通往老鹰的桥。

  2. 02

    在尝试他们的方块拼图之前先清理敌人的房间。弓位于侧视宝藏室中：在离开之前收集它，即使这个地牢的首领不需要它。

  3. 03

    跟踪上锁的门并将钥匙花在未探索过的树枝上。从火球线旁边击败阿奎门图斯，然后收集心之容器和三角神力碎片。

02

月亮与万吉

0 / 3 步骤+

开通水上航线。

攻略路线与谜题解法

  1. 01

    使用可用的炸弹探索东部树林中的月球。多东戈吞下放在嘴前的炸弹；用剑攻击它的铠甲身体是无效的。

  2. 02

    在Manji中，从后面或从他们没有防护的一侧接近Darknuts。在前往 Boss 之前，从地下室取回木筏。

  3. 03

    Manhandla 失去头后会变得更快。将炸弹放置在几个头重叠的地方可以缩短战斗时间；撤退并重新定位，而不是交换损失。

03

蛇

0 / 3 步骤+

获得梯子。

攻略路线与谜题解法

  1. 01

    站在西岸的码头上，让木筏带你前往岛屿地牢。带上一支蜡烛来揭示敌人并从黑暗的房间中退出。

  2. 02

    找到梯子，然后重新访问被一格水打断的通道。在合适的间隙自动工作；它不能带你穿过一个湖。

  3. 03

    格利奥克的头颅仍然很危险。将攻击集中在仍然附着在身体上的头部，同时远离脱离的头部。

首领战提示

攻击格利奥克的附加头，同时避开分离的头。

04

蜥蜴

0 / 3 步骤+

取得笛子。

攻略路线与谜题解法

  1. 01

    在失落之丘，反复走北出口到达地牢。首先补充炸弹：几个连接隐藏在看似普通的墙壁内。

  2. 02

    使用地下通道网络到达记录器。从侧面耐心地与蓝色黑坚果战斗，避免被包围。

  3. 03

    在 Digdogger 的房间里吹奏笛子来改变它的形态，然后切换回剑。如果你有十二个心之容器，那么在进入后面的关卡之前，魔法剑是一个有用的绕道。

05

龙

0 / 3 步骤+

确保片段六。

攻略路线与谜题解法

  1. 01

    带着箭和一些卢比进入墓地地牢。每支箭消耗一卢比，因此仅购买箭是不够的。

  2. 02

    观察维兹罗布出现的位置，然后在齐射之间发起攻击。远离“点赞”，这会消耗更大的护盾。

  3. 03

    在地下室找到魔法棒。对抗戈玛时，直接在它的眼睛前面排成一行，当它的眼睛睁开时释放一支箭。

06

恶魔

0 / 3 步骤+

排空隐蔽入口。

攻略路线与谜题解法

  1. 01

    在前往没有仙女的西池之前购买食物。在该屏幕上吹奏笛子以显示入口。

  2. 02

    饥饿的戈里亚会阻止前进，直到你给它食物。使用炸弹调查死胡同并在途中收集红蜡烛。

  3. 03

    将重复出现的 Boss 视为资源检查：使用 Digdogger 上的笛子并从火球传播范围之外攻击 Aquamentus。为他们之外的隐藏路线保留备用炸弹。

07

狮子

0 / 3 步骤+

完成智慧三角力。

攻略路线与谜题解法

  1. 01

    烧毁东南部树林中可疑的灌木丛以发现狮子。进行治疗并避免带着空炸弹进入最困难的房间。

  2. 02

    在楼梯通道中搜索魔法钥匙和魔法书。该钥匙可以打开上锁的地牢门，而无需使用剩余的小钥匙。

  3. 03

    不要仅仅因为找到了通往格利奥克的路线就停止探索。获取地牢宝藏，击败它的多个头并收集第八个三角神力碎片。

08

死亡之山

0 / 3 步骤+

准备可以杀死加农的武器。

攻略路线与谜题解法

  1. 01

    轰炸奇观岩西部岩石的南面。所有八个碎片都需要通过里面的守护者。

  2. 02

    将楼梯通道映射为成对的相连房间；他们的出口可能相距很远。在测试可移动方块之前击败所有敌人，并在可见路线结束时检查可轰炸的墙壁。

  3. 03

    在最后进场前收集红环和银箭。戒指可以减少传入的伤害；最后一击需要箭头。

09

最后的箭头

0 / 3 步骤+

拯救塞尔达。

攻略路线与谜题解法

  1. 01

    带上药品和足够的卢比来发射箭。观察加农火球的来源来估计他的隐形位置并用剑攻击。

  2. 02

    当反复的剑击使他变红且脆弱时，立即发射银箭。普通的箭无法完成战斗。

  3. 03

    收集他留下的三角神力，进入塞尔达的房间并切断火焰。结局解锁了单独的第二个任务。

心脏容器和永久设备

  1. 01

    在前八个地下城首领之后收集心脏容器。探索世界，寻找另外五个补给箱；当老人提供药物或心脏时，请选择永久完成的心脏。

  2. 02

    使用木筏和梯子重新审视海岸线奖励。分别检查剑的阈值：白剑为五心，魔剑为十二心。

  3. 03

    在预算允许的情况下购买蓝环，升级5级和7级的炸弹容量，并在进入死亡山之前检查装备清单。后来红环取代了蓝环。

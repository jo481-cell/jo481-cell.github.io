01

梅西与第一精神

0 / 3 步骤+

营救莱恩贝克并到达余烬岛。

攻略路线与谜题解法

  1. 01

    拿起奥修斯的剑，练习所需的攻击并进入海洋王神殿营救莱恩贝克。在沙漏到来之前，避免在安全区外徘徊。

  2. 02

    在余烬岛上，阅读坟墓并标记正确的位置以释放阿斯特丽德。爬向寺庙并用麦克风熄灭入口蜡烛。

  3. 03

    获取回旋镖并绘制穿过多个目标的路径。在布拉兹的战斗中，阅读屏幕上方图像上的角并按顺序连接三种形态。

02

西北海域

0 / 3 步骤+

恢复智慧之灵。

攻略路线与谜题解法

  1. 01

    带着幻影沙漏返回查看下一张海图。使用安全区来停止计时器并在穿越前等待幻影巡逻队。

  2. 02

    购买大炮并按照莫利达隐藏的藏身处记录的路线穿越迷雾。使用岛屿线索激活阵风岛的风车。

  3. 03

    在风神殿收集炸弹。当小旋风经过独眼巨人下方时，将炸弹扔进其中，然后攻击倒下的 Boss。

03

海上的一个印记

0 / 3 步骤+

寻找第三个灵魂。

攻略路线与谜题解法

  1. 01

    返回海洋王的神庙，并在显示两个相关屏幕时通过关闭并重新打开 DS 来传输神圣印记。仅当您的平台提供了等效的盖子控件时才使用该控件。

  2. 02

    在标记的海域购买打捞臂并取回太阳钥匙。返回莫利达，打开太阳门，进入勇气神殿。

  3. 03

    获得弓并使用地牢的线索沿着看不见的路线前进。对抗克雷克，瞄准屏幕上方显示的视点，然后攻击暴露的贝壳生长和尾巴。

04

幽灵船

0 / 3 步骤+

找到泰特拉。

攻略路线与谜题解法

  1. 01

    跟随灵魂的信号穿过迷雾，直到到达船上。探索甲板并护送姐妹们，同时观察巡逻的敌人。

  2. 02

    根据实际房间线索验证姐妹们的说法。在移动被护送的角色之前，规划好围绕尖刺和桶的路线。

  3. 03

    用剑返回库布斯姐妹的固体能量球，同时避开误导性的射弹。找到 Tetra 后，访问 Zauz 以了解幻影之剑需要哪些金属。

05

第一个纯金属

0 / 3 步骤+

恢复猩红。

攻略路线与谜题解法

  1. 01

    返回中央神殿查看东南海图，然后与戈隆岛上的所有戈隆人交谈。使用居民告诉你的内容回答 Biggoron 的问题。

  2. 02

    在 Link 和 Kongoron 之间交替以保持开关并打开路径。通过小孔绘制 Bombchu 路线，到达对面的开关。

  3. 03

    使用贡戈隆将唐戈隆戈击倒，然后将炸弹送入其嘴中。后期在其吸入的地方放置炸弹，然后攻击暴露的身体。

06

冰冻的岛屿

0 / 3 步骤+

回收天青。

攻略路线与谜题解法

  1. 01

    比较 Anouki 的陈述，找出伪装的 Yook。清理雪原路线，进入冰之神殿。

  2. 02

    抓钩可以将柱子连接成绳子。使用绳索作为桥梁或跳板，并在直接路径受阻时拉动远程开关。

  3. 03

    用斜绳将格利奥克的火和冰射击重定向到相反颜色的头部。然后，将舌头固定在柱子上，将头部拉低以进行剑攻击。

07

淹没的王国

0 / 3 步骤+

回收阿奎宁。

攻略路线与谜题解法

  1. 01

    阅读死亡之岛的线索并获得帝王项链。在废墟岛上，拜访皇家神灵并降低水位以暴露寺庙通道。

  2. 02

    在武藤寺收集锤子。在发射平台和楼层开关模式上使用它；在重复敲击相邻的瓷砖之前弄清楚它们如何变化。

  3. 03

    启动 Eox 标记弱点的林克并锤击它们。身体破碎后，落在剩下的头上并攻击其暴露的宝石。

08

幻影之剑

0 / 3 步骤+

释放海洋之王和泰特拉。

攻略路线与谜题解法

  1. 01

    将三种纯金属带到扎乌兹，并将锻造的刀片带到奥修斯。返回海王神殿；完成的剑现在可以从背后击败幻影。

  2. 02

    拉开贝鲁姆的粘液，然后射击竞技场周围的眼睛。当所需的开口出现时，使用 Ciela 的时间停止能力。

  3. 03

    船战结束后，与附身的莱贝克战斗。观察屏幕上方他背后睁开的眼睛，停止时间并移动到他身后进行攻击。

进度检查点

首领战提示

抓住贝鲁姆的粘液并射击它的眼睛；在附体与莱贝克的决斗中，当上方屏幕显示其后眼睁开时，时间停止。

实用提示

西拉的时间停止能力只有在收集到所需的幻影球体后才会发挥作用。

高效回报，剩余宝藏

  1. 01

    使用炸弹、箭和后来用来创建捷径的工具重温早期的寺庙地板。一旦新物品打开了直接通道，之前的安全路线就变得不必要了。

  2. 02

    使用可用的最佳检查点时间，进行治疗并在地图上标记重要符号。更多的时间沙子提供了灵活性，但并不能取代安全区规划。

  3. 03

    为了完成任务，请重新访问岛屿以获取灵魂宝石、爱心、藏宝图和船舶部件。对于各个地点，请使用以下客观参考；随机的船舶部件奖励可能需要重复活动。

大哥隆之剑交换任务

需要携带

  • 用于跨越格鲁德山谷断桥的艾波娜或长钩爪
  • 建议准备：艾波娜、钩爪，以及童年时期种在多东哥洞窟外的魔法豆

从轻微提示开始，或直接查看下方路线。

01一点小提示+

先找卡卡利科照顾咕咕鸡的人。第一件差事与其说是打怪，不如说是叫醒一个睡着的人。

02更明确的方向+

每次交换都会指向下一个人。蘑菇、青蛙和眼药水这三样有时限；接受之前先规划路线。

03最后的提示+

最后一位工匠是死亡之山山顶的大哥隆。修剑之前，先帮他治好眼睛。

准备好了就出发完整路线+

从成年时期卡卡利科养鸡女子给的袖珍蛋开始，一路交换到大哥隆，送达眼药水，再过三个游戏日带着取货凭证回来。

  1. 袖珍蛋 → 科吉罗

    从养鸡女子那里取得蛋。过夜孵化后，在卡卡利科井边的房屋里用袖珍咕咕鸡叫醒塔隆，再交还女子，换取科吉罗。

  2. 科吉罗 → 奇怪蘑菇 → 奇怪药剂

    进入迷失森林后第一个岔路向左，向树桩旁的男子展示科吉罗。三分钟内把蘑菇送给婆婆；白天可从卡卡利科药店后方前往。

  3. 奇怪药剂 → 偷猎者的锯子

    返回迷失森林的同一片空地。男子已不见，把药剂交给现在站在那里的科奇里女孩。

  4. 偷猎者的锯子 → 断裂的咕隆剑

    用艾波娜或长钩爪跨过格鲁德山谷的断桥，把锯子交给对面的木匠头领。

  5. 断剑 → 处方

    抵达死亡之山山顶，向火山口入口附近的大哥隆展示断剑，并接下他的处方。

  6. 处方 → 眼球蛙

    如有需要，用瓶装蓝色火焰解冻佐拉王。准备好出发后再出示处方。必须在三分钟内把青蛙送到海利亚湖湖畔研究所的科学家手中。

  7. 眼药水 → 取货凭证

    科学家给的眼药水有四分钟时限。骑马穿过海拉鲁平原到卡卡利科，沿死亡之山山道上山，交给大哥隆。在多东哥洞窟外种过魔法豆可以缩短登山路程。

  8. 取货凭证 → 大哥隆之剑

    等三个游戏日后，向大哥隆出示取货凭证。在户外演奏六次太阳之歌可推进三个昼夜周期；每次都要等转换完成。

接受计时任务前做好准备

穿越广阔平原时使用艾波娜。领取易腐物品前先熟悉研究所和山路。传送歌曲会使限时物品变质，请直接穿行海拉鲁完成配送。

给原版N64全收集玩家

取得偷猎者的锯子后，森林舞台的德库坚果容量升级可能无法再获得。想要这项升级的话请先取得；这是原版的一个特殊问题。

分清两把剑

商店购买的巨人小刀不是前置条件，而且会断。完成的大哥隆之剑很耐用，但需要双手持握，举盾前必须收剑。

拿到奖励后，就勾选完成吧。

01

伟大的天空岛

0 / 3 步骤+

打开时间神殿。

攻略路线与谜题解法

  1. 01

    完成前三个神殿以学习 Ultrahand、Fuse 和 Ascend。利用这些能力建造十字路口、组合武器并攀爬坚固的天花板。

  2. 02

    返回时间神殿进行召回，然后到达第四个神殿。水车反转打开了以前无法到达的路线。

  3. 03

    将四颗祝福之光换成心之容器，然后打开大门。沿着最后的天空岛路径前进，然后潜入下面的水中。

02

了望台

0 / 3 步骤+

获得滑翔伞。

攻略路线与谜题解法

  1. 01

    在 Lookout Landing 与 Purah 会面，并向城堡第一门楼附近的 Hoz 报到。返回解锁塔并获得滑翔伞。

  2. 02

    使用塔楼和附近的神社建立旅行点。接受地区现象调查，为第一个目的地收集衣物和食物。

  3. 03

    跟随罗比的相机深度探险。带上 Brightbloom 种子并在 Lightroots 之间标记一条路线，以便第一次地下旅行保持可控。

03

图林与风神庙

0 / 3 步骤+

到达赫布拉上方的风暴。

攻略路线与谜题解法

  1. 01

    帮助图林找回他的弓，然后沿着上升的岛链前进。仅当他的阵风带你到达可到达的平台或弹起的帆时才使用他的阵风。

  2. 02

    在风神殿内，打开所有五个涡轮锁。探索船的侧面和下部通道；有些机械装置需要 Ultrahand 修复后，图林才能为其提供动力。

  3. 03

    通过潜入暴露的板块或从下方射击来打破科尔格拉的冰冷弱点。保持足够的距离以读取其再现并避开龙卷风。

04

汤诺博与火神庙

0 / 3 步骤+

追踪大理石烤肉。

攻略路线与谜题解法

  1. 01

    打破尤诺博的面具并跟随他登上死亡山。使用提供的飞行器和尤诺博的冲锋攻击火山口的岩石头。

  2. 02

    下降到裂缝中，沿着雕像路线前往火神庙。切换矿车轨道并使用坡道将尤诺博发射到五个锣中。

  3. 03

    用尤诺博打断大理石戈玛的腿，露出眼睛。在天花板阶段，让尤诺博爬上弯曲的墙壁，然后爬到倒下的 Boss 上进行攻击。

05

西顿和水神庙

0 / 3 步骤+

清除污泥。

攻略路线与谜题解法

  1. 01

    恢复佐拉盔甲并调查托托破碎的石板。找到多瑞芬国王，然后从浮鱼岛上看到的水滴状结构中射出王者之鳞。

  2. 02

    清理古佐拉水厂堵塞的管道，爬上瀑布到达泉水岛。在水神殿中，使用西顿的水能力操作四个水龙头。

  3. 03

    用水攻击冲走穆克托罗克的污泥鲨。追逐并攻击暴露的生物；当污泥块妨碍您安全移动时，请清除它们。

06

利珠与闪电神殿

0 / 3 步骤+

结束沙罩。

攻略路线与谜题解法

  1. 01

    帮助 Riju 保卫卡拉卡拉集市和格鲁多镇。沿着壁画的柱子排列线索找到神庙，然后在吉布多女王的第一次攻击中幸存。

  2. 02

    在寺庙内，跟随光束并旋转或移动镜子以露出四个电池室。站在 Riju 附近，向每个目标发射一支箭，使其充满闪电。

  3. 03

    在攻击前使用闪电或其他有效元素削弱吉布多女王。当巢穴的核心暴露时摧毁它们，并利用产生的光来管理较小的吉布多斯。

07

假公主

0 / 3 步骤+

解决城堡目击事件。

攻略路线与谜题解法

  1. 01

    完成四个区域任务后，向普拉报告。按照调查显示的顺序，跟踪公主在漂浮城堡中的目击事件。

  2. 02

    在伏击之间补充能量并保留返回安全壁架的路线。目击事件在不同楼层之间移动，因此请阅读地图上的垂直位置。

  3. 03

    在贤者的帮助下，对抗圣所中的幻影加农集团。避开阴暗的地面，然后返回瞭望台寻找下一条线索。

08

第五圣人

0 / 3 步骤+

建造 Mineru 的身体。

攻略路线与谜题解法

  1. 01

    调查环形遗迹并跟随陶罗前往德拉科祖。完成充能护甲仪式，然后穿过雷头群岛到达龙头岛。

  2. 02

    用十颗心打开门，并沿着指示的路线携带 Mineru 的面具。将所有四个仓库肢体交付给建造工厂并组装车身。

  3. 03

    乘坐 Mineru 前往神殿。格挡被抓住的构造体的攻击，连续攻击使其错开，并将其推入带电边界。

09

夺回英雄的剑

0 / 3 步骤+

准备最后的下降。

攻略路线与谜题解法

  1. 01

    调查地痕和大德库树的问题，以了解剑的下落。这棵树可以为光龙提供移动的任务标记。

  2. 02

    从高的发射点到达龙并降落在它的头部附近。拔剑需要两个完整的永久耐力轮，而不是临时的黄色耐力。

  3. 03

    在最后的下降之前，准备强大的融合武器、箭、治疗和食物，以恢复黑暗受损的心脏。暂时的最大心力损失需要适当的恢复。

10

海拉鲁城堡下方

0 / 3 步骤+

击败加农多夫。

攻略路线与谜题解法

  1. 01

    通过地下通道下降到海拉鲁城堡下方，面对怪物大军。为魔王保留补给，而不是将一切都花在早期的敌人身上。

  2. 02

    加农多夫可以躲避你的攻击。阅读他的后续行动并反击这个空缺，而不是立即重复同样的攻击。

  3. 03

    在空降大结局中，使用光龙恢复高度。摧毁魔龙背上脆弱的生长物，然后攻击它头上的石头。

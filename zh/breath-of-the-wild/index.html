01

大高原

0 / 3 步骤+

赢得滑翔伞。

攻略路线与谜题解法

  1. 01

    启动大高原塔并完成四项神殿试炼。 Magnesis 可以移动金属，炸弹可以清除障碍物，Stasis 可以储存对冰冻物体的影响，Cryonis 在水中可以制造柱子。

  2. 02

    攀登雪域神社前请做好防寒准备。煮热食或穿合适的衣服，并观察保护计时器，而不是仅仅依靠一顿饭。

  3. 03

    在女神雕像处交换四颗灵珠，然后在时间神殿上方与老者见面。获得滑翔伞后才能离开高原。

02

卡卡里科和哈特诺

0 / 3 步骤+

恢复林克的方向和记忆。

攻略路线与谜题解法

  1. 01

    穿过决斗山峰前往卡卡里科并与因帕交谈。登记一匹马或激活沿路的神社，让回程更加轻松。

  2. 02

    在哈特诺的实验室，从村庄的熔炉中带出蓝色火焰，使用沿途的灯笼作为重新点燃点。解锁相机并拍摄所需的照片。

  3. 03

    返回Impa并开始记忆搜索。收集古代材料用于符文升级，并在有能力改善盔甲时拜访伟大的仙女。

03

佐拉的领地和瓦鲁塔

0 / 3 步骤+

帮助西顿平静水库。

攻略路线与谜题解法

  1. 01

    沿着通往佐拉领地的道路并接受西顿的计划。在莱内尔领地周围收集冲击箭；不需要击败莱内尔。

  2. 02

    骑在希多背上，用制冰器击碎飞来的冰块，攀上瀑布后射击露塔发光的目标。进入内部取得地图，再改变象鼻的位置来驱动水车。

  3. 03

    激活主控制之前的所有五个端子。对抗水疫病，攻击它的眼睛并躲避长矛；在被淹没的阶段，打破或返回其冰块并使用箭头创建一个开口。

04

Rito 村和 Vah Medoh

0 / 3 步骤+

夺回天空。

攻略路线与谜题解法

  1. 01

    到达Rito村，与长者交谈并在飞行靶场与Teba会面。进攻前带上防寒装备并练习空中射箭。

  2. 02

    在射击窗口之间滑行时，用炸弹箭摧毁 Medoh 的大炮。在里面，倾斜野兽并使用气流、滑动机制和炸弹到达航站楼。

  3. 03

    利用上升气流来对抗风枯草，并以慢动作射击它的眼睛。避开龙卷风，并在浮动装置改变攻击方式时重新定位。

05

戈隆市和瓦鲁达尼亚

0 / 3 步骤+

安全攀登死亡山。

攻略路线与谜题解法

  1. 01

    在进入燃烧山区之前，请先获得火焰保护。沙漠的耐热性并不能抵御这种环境。

  2. 02

    释放尤诺博，护送他通过侦察兵并使用大炮。在鲁达尼亚内，点燃淡蓝色火焰火把打开路线，然后旋转野兽到达剩余的终点站。

  3. 03

    当火疫病在其火焰屏障后面吸入空气时，将远程炸弹扔进吸力并引爆。结界破裂后攻击，避开大剑挥击。

06

格鲁多镇和瓦纳博里斯

0 / 3 步骤+

归还雷霆头盔。

攻略路线与谜题解法

  1. 01

    按照要求的伪装进入格鲁多镇，从伊加藏身处取回雷霆头盔，然后返回里朱。在接近过程中，留在她的保护范围内。

  2. 02

    获得纳波利斯的地图并旋转其三个身体部分以连接电路。沿着动力电梯和外部路线前往航站楼。

  3. 03

    格挡或躲避雷霆荒野的冲锋并打破它的防御。在金属柱阶段，使用磁力提升 Boss 附近的一根柱子，使其自身的闪电击中它。

07

记忆与森林之剑

0 / 3 步骤+

选择结局前的准备工作。

攻略路线与谜题解法

  1. 01

    沿着失落森林的风线索前往科罗克森林。拔出大师剑需要十三颗永久心；暂时的黄心不算数。

  2. 02

    使用相册和 Pikango 的线索访问记忆位置，然后向 Impa 报告最终的记忆线索。到达加农的记忆是可选的。

  3. 03

    升级盔甲、准备治疗并收集盾牌、箭和备用武器。在进入城堡之前选择您想要完成的剩余神殿和支线任务。

08

海拉鲁城堡

0 / 3 步骤+

结束灾难。

攻略路线与谜题解法

  1. 01

    选择适合您的设备的城堡路线：水、悬崖和内部走廊提供不同的路线。进入圣所之前，先前往侧室获取补给。

  2. 02

    任何未清理的神兽boss都必须在天灾加农之前进行战斗。当他的保护激活时，使用闪避、招架和冠军的力量来创造空当。

  3. 03

    在黑暗野兽加农期间，对发光目标使用光之弓。骑在野兽周围，然后利用上升气流和空中瞄准最后一只眼睛。

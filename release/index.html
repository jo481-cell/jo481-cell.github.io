The release dossier

Nintendo has set the return to Hyrule for November 5, 2026. This record keeps the practical details in one place.

Last verified October 9, 2026 · 4 chapters

On this page01 When it releases02 Download and display03 Play modes and save data04 What can still changeView the sources ↗

Chapter 01

When it releases

The official Nintendo listing gives a release date of November 5, 2026. The game is exclusive to Nintendo Switch 2.

  • Date: November 5, 2026
  • System: Nintendo Switch 2
  • Players: 1

Chapter 02

Download and display

Nintendo currently estimates a 27 GB file size. The listing also includes HDR output and VRR output for compatible televisions, plus surround sound through linear PCM.

Chapter 03

Play modes and save data

TV, tabletop and handheld modes are supported. The product page lists Save Data Cloud through Nintendo Switch Online.

Chapter 04

What can still change

Nintendo warns that information such as ratings and download size may not be final before release. Treat 27 GB as the current official estimate, not a guaranteed launch-day size.

01

プリンセスと塔

0 / 3 ステップ+

森林鉄道の地図を回収します。

攻略ルートと謎解き

  1. 01

    エンジニアの旅を完了し、ゼルダが見つからずに城を出るのを手伝ってください。リンクが警備員の注意をそらしている間、彼女を安全な位置の間で誘導します。

  2. 02

    精霊の塔で光の涙を3つ集めて剣に力を与えます。ファントムを後ろから攻撃すると、ゼルダが憑依できるようになります。

  3. 03

    リンクがスイッチを操作している間、ゼルダの鎧を使って危険を越えたり、他のファントムの気をそらしたりしましょう。出発前に森林鉄道マップを入手してください。

02

森の王国を回復する

0 / 3 ステップ+

最初のロコモ デュエットを完了します。

攻略ルートと謎解き

  1. 01

    手がかりによって与えられた最後の例外を含め、迷いの森を通って木の指示に従ってください。ゲージに連絡して、デュエットの前にフルートのシーケンスを練習してください。

  2. 02

    森の寺院内では、Whirlwind を使用して鍵を動かし、有毒な霧を取り除き、気絶させた爆発的な敵を障害物に向かって送ります。

  3. 03

    スタグノックスの後部を守る雲を吹き飛ばし、攻撃します。飛行フェイズ中に、爆発する敵をボスに吹き込み、ボスを倒します。

03

雪に覆われたトラック

0 / 3 ステップ+

2 番目の領域を復元します。

攻略ルートと謎解き

  1. 01

    次のタワーセクションを完了して、スノーレールマップを入手してください。アヌーキとフェラスの手がかりを使って、吹雪の中を通るルートを見つけてください。

  2. 02

    スティームのデュエットの後、雪の神殿に入り、ブーメランを集めます。その要素を運ぶために、意図したターゲットの前に火または氷の中の道を描きます。

  3. 03

    フラーズを反対の要素で攻撃します。元の松明が破壊されたら、彼の攻撃によって残された火と氷を新しい元素のソースとして使用します。

04

0 / 3 ステップ+

攻略ルートと謎解き

    オーシャンレールマップを回収し、壊れた橋の修理を手配し、カルベンをパプチアから連れ戻します。彼のデュエットは水中ルートへの道を復元します。

  2. 02

    オーシャンテンプルで鞭を入手し、ポール、ハンドル、スイッチに使用します。ランダムなシーケンスを引く前に、剣の柄のヒントを読んでください。

  3. 03

    フィトプスの巻きひげからとげを引き抜き、保護されている目に向かって投げます。覆いを取り除き、目を気絶させ、剣で攻撃します。

05

ゴロンと火の神殿

0 / 3 ステップ+

06

塔の頂上

0 / 3 ステップ+

攻略ルートと謎解き

  1. 01

    精霊の塔に戻り、特定の障害物に対してさまざまなファントム フォームを使用します。保護されたルートや重いルートでは、ゼルダがリードする必要がある場合があります。

  2. 02

    バーンとの戦い中、ゼルダが伸ばした爪をキャッチできる場所にゼルダを配置します。彼女が彼を保持している間にリンクを攻撃できる位置に移動します。

  3. 03

    塔のシーケンスの後は、アンジャンの新しいリードに従います。塔の見かけの修復だけで物語が終わるわけではありません。

07

光の弓

0 / 3 ステップ+

闇の領域に備えましょう。

攻略ルートと謎解き

  1. 01

    ラエルに到達し、デュエットを完了し、鉄道の試練に合格してください。砂の神殿に入り、砂の杖を回収します。

  2. 02

    リンクの下の砂や重い物体を持ち上げて棚に到達したり、障壁を移動したりできます。一時的な砂のプラットフォームは崩れるので、作成する前に次の動きを準備してください。

  3. 03

    盛り上がった砂でスケルドリッチの転がる岩をキャッチし、鎧の中に発射します。露出した弱点に到達し、戦闘後に光の弓を回収します。

08

最後の登り

0 / 3 ステップ+

光のコンパスを見つけてください。

攻略ルートと謎解き

  1. 01

    光の弓を持って精霊の塔に戻ります。光に敏感なターゲットを操作するときにショットをチャージします。

  2. 02

    トーチ ファントムを使用して暗いルートを照らし、ワープ ファントムを使用して適切なターゲットに到達し、レッカー ファントムを使用して重い障害物を破壊します。

  3. 03

    最後の部屋全体でゼルダの位置とリンクのスイッチを調整します。光のコンパスを手に取り、新たに明らかになった軌跡をたどり、闇の領域へ向かいましょう。

09

ダークレルム

0 / 3 ステップ+

マラダスを倒す。

攻略ルートと謎解き

  1. 01

    光の涙を集めて列車を一時的に無敵にし、装甲列車に体当たりします。攻撃を避けるために線路を切り替えながらデーモントレインの武器を破壊してください。

  2. 02

    ゼルダをコールの前に誘導して、彼女がマラダスを拘束し、光の弓を撃てるようにします。次のフェーズで彼女を保護し、フルートの二重奏を完成させてください。

  3. 03

    マラドゥスの向きを変えて、ゼルダが背中を撃てるようにします。転倒時に額の宝玉を叩きつけ、最後の合体攻撃を完成させる。

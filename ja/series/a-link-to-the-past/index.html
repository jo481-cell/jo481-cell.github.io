01

光の世界 · 雨と城と秘密の通路。

雨の夜の救助

出発する前にアイテムは必要ありません

報酬剣・盾・カンテラ・教会のハートのうつわ

  1. 家の中にある宝箱を開けてランタンを入手します。雨の中を抜け出し、北にある城へ向かいます。

  2. 東の庭で、一本の茂みを持ち上げて穴に落とします。叔父に話しかけて剣と盾を受け取り、地下通路を通って中庭へ進みます。

  3. 城に入り、ダンジョンに降りて衛兵から鍵を集めます。ブーメランを手に取って敵を動けなくしてください。

  4. ゼルダの独房の外にあるボールとチェーンの警備員に壺を投げたり、攻撃の合間に攻撃したりしましょう。 大きなカギを集め、独房のロックを解除し、ゼルダに話しかけます。

  5. 玉座に戻りなさい。家具を右に押します。暗い通路を渡ります。宝箱から鍵を入手し、次に下水道のネズミから鍵を入手します。

  6. 通路の中央ブロックを上に押します。最後の部屋で右側のレバーを引きます。賢者の言うことを聞いて、ハートのうつわを受け取りましょう。

この章のヒント +

ゼルダへの道は、警備されたドアの隣から始まります。

解決策を明らかにする

城を右に回り込み、孤立した茂みを持ち上げます。救出後、玉座の後ろの家具を左から押します。

02

光の世界 · カカリコ村があなたのホームベースになります。

カカリコ村で準備をする

出発する前にゼルダの聖域

報酬ネット、ボトル、そしてサハスラーラとの出会い

  1. 西のカカリコ村に向かい、サハスラーラについて尋ねてください。彼の隠れ家は東の遺跡の近くにあります。

  2. 村の商人のために100ルピーを保管してください。購入したボトルを使用すると、ポーション、妖精、または蜂を運ぶことができます。

  3. 酒場の北側に回って裏口を利用します。この小さな部屋にある宝箱を開けて 2 番目のボトルを入手します。

  4. 家にいる病気の子供に話しかけてください。網で妖精を捕まえて、空の瓶を選びます。彼女は敗北後にあなたを助けてくれるでしょう。

  5. 爆弾を使って村の井戸や盗賊の隠れ家の地下を探索してください。収集したハートのかけらをマップのハートフィルターでマークします。

  6. 東の神殿の南西にある小さな家に行きます。サハスラーラと話し、宮殿の入り口に向かいます。

この章のヒント +

よく探索された村では、生き残るチャンスがいくつかあります。

解決策を明らかにする

商人からボトルを購入し、酒場の裏に入り、病気の子供に話しかけて網を入手してください。

03

光の世界 · 初めてのペンダント・狙い方を学ぶ。

東の神殿

出発する前に剣 · ランタン

報酬弓、勇気のペンダント、ペガサスの靴

  1. 中央のポットを持ち上げてドアを開けます。床の間を避難所として使用して、砲弾が飛び交う廊下を渡ります。

  2. アクセス可能な翼で地図とコンパスを収集します。中央にある大きな宝箱を見つけてください。 大きなカギで戻ります。

  3. 東棟の暗い部屋を通ってください。スケルトンルームの右上隅からポットを持ち上げます。

  4. 西棟へ行きます。覚醒したアイゴールを含む敵を倒します。彼らが守っていたポットを持ち上げ、床スイッチを使用して大きなカギを入手します。

  5. 大宝箱に戻って開けます。北のドアを通過する前に、ポットの下に矢を集めてください。

  6. アイゴールを目覚めさせ、開いた目を攻撃します。赤いアイゴールには矢印が必要です。落とした鍵を回収し、最後の部屋のスイッチを作動させます。

  7. アルモスを倒し、ハートとペンダントを手に入れます。両方の報酬なしでボスルームを出ないでください。

  8. シェルターに戻ってペガサスの靴を入手してください。それらを使用すると、物体にぶつかったり、図書館の本に到達したりできます。

この章のヒント +

大きな宝箱が最初の目的地ではありません。

解決策を明らかにする

西の部屋の敵を倒し、バブルに囲まれた壺に到達します。持ち上げてスイッチを踏むと、大きなカギが表示されます。

ボス デグアモス ↗

6 つの彫像が生き生きとしているときに撃ってください。ラウンド中は後ろにいてください。彼らが突撃するときは脇に移動してください。最後の騎士があなたに飛びかかります。移動してから撃ちます。

光の世界 · 2番目のペンダント · 砂の下の強さ。

砂漠の神殿

出発する前にペガサスの靴 · ムドラの書 · ランタン

報酬パワーグラブとペンダント

  1. カカリコ村の南、図書館の棚にブーツをぶつけます。 ムドラの書を選択してください。

  2. 南西の砂漠で、本のある中央の碑文を読んでください。通路が開いたら入ってください。

  3. 最初のセットの北西を探索します。鍵を持った支柱にぶつかって落下させます。

  4. このキーを東に使用します。敵を排除し、発射物の廊下を渡って大きなカギに到達します。

  5. 西に戻ります。鍋の下に隠されたスイッチを押すと、大きな宝箱の部屋が開きます。手袋を入手してください。

  6. 南西に出てください。 ハートのかけらの棚を降りてください。戻って北入口前の石を持ち上げます。

  7. 空飛ぶタイルの部屋の間を移動し、ポットの下にある鍵を入手します。最後の部屋で、4 つの松明に火をつけます。

  8. 3匹のランモーラを倒し、ハートのうつわとペンダントを手に入れます。

この章のヒント +

外側の出口はダンジョンの一部です。

解決策を明らかにする

西棟でパワーグラブを手に入れ、外の足場に出て、白い岩の奥にある北側の入口へ進みます。

ボス ランモラス ↗

砂の動きに注意してください。斜めの破片から遠ざけて、出てくる頭を打ちます。最後のワームはさらに石を投げます。スペースを与えてください。

デスマウンテンを登る

光の世界 · 3番目のペンダント・パールを忘れないでください。

ヘラの塔

出発する前にマジカルミラー · ランタン

報酬ムーンパールと最後のペンダント

  1. 青いブロックを下ろして下へ進みます。小さな鍵を手に取り、クリスタルを調整して上に戻れるようにします。

  2. ダンジョンマップを集めます。クリスタルスイッチは色付きのバリアを変更します。スタースイッチは床の穴を変更します。

  3. 北西の通路を開き、飛び散るタイルを乗り越えて、4 つの松明のある部屋に到達します。点灯すると、大きなカギが表示されます。

  4. 戻って上の階段を上ります。カブトムシを穴から遠ざけ、コンパスを回収します。

  5. 上の階では、星を使って対応する穴を開けます。北端から落ちて宝箱を開けてムーンパールを入手します。

  6. 再び階段を登ります。ハートをポットの下に置いてモルドルムの前で回復し、彼のアリーナに入ります。

  7. 勝利後、ハートとペンダントを受け取ります。山を出る前に、パールが在庫にあるかどうかも確認してください。

この章のヒント +

星は穴を移動し、落下はあなたを助けてくれます。

解決策を明らかにする

大きな宝箱の上の階で、回転する炎の近くにある星を起動します。バンパーの北端から北の穴に近づき、下に降ります。

ボス モルドルム ↗

尻尾の先端だけを叩きます。プラットフォームの中央を維持し、端での交換を避けてください。転倒が彼の人生をリセットする。階段を通って戻ります。

マスターソードと魔術師

出発する前にペンダント 3 個 · ムーンパール

報酬マスターソードと暗闇の世界への永続的なアクセス

  1. 迷いの森で、台座の空き地に到達します。 3 つのペンダントでは、マスターソードを取り外します。森の中の他の剣はおとりです。

  2. ゼルダの聖域への呼びかけに従ってください。現在も城の頂上で救助活動が続いている。

  3. 城の上部テラスで、マスターソードで魔法のバリアを打ち、塔に入ります。

  4. 上に上がって暗い部屋を照らし、警備員を排除して鍵を入手します。壺は武器として機能し、資源が含まれています。

闇の神殿

出発する前にムーンパール · 弓 · 爆弾 · キキ 110ルピー

報酬マジックハンマーと最初のクリスタル

  1. ピラミッドから東の遺跡を横切ります。猿にお金を払ってついて来てもらい、宮殿を開けてもらいます。彼を怖がらせるような打撃を避けてください。

  2. スイッチを使って左側にある地下室の鍵を入手します。右側にあるテレポーターはゴリヤの部屋と地図につながります。

  3. マップルーム近くのひび割れた壁を爆撃します。赤いゴリヤを攻撃するには、矢を放ち、敵が自分をその進路に映すように移動します。

  4. 中央ルートに戻ります。マークされたギャップで下のレベルにドロップすると、大きなカギの宝箱に到達します。フロアマップを使用して接続をたどります。

  5. 崩れ落ちた橋を急いで渡ります。迷路では、南東の鍵を取得し、東の壁を爆撃してマジックハンマーに到達します。

  6. 亀の敵を攻撃する前に、マジックハンマーで敵をひっくり返します。コンパスと下層階の鍵を回収し、スイッチと緑の像まで戻ります。

  7. 像のボタンを押したまま、緑の目を撃ち、降下します。クリスタルとテレポーターがボスにつながります。

  8. ヘルマサウルスを倒し、ハートとクリスタルを手に入れましょう。 マジックハンマーは多くの外部通路を開くようになりました。

マジックハンマーまたは爆弾で彼のマスクを破壊します。緑色の宝石を見つけたら、剣または矢を使用します。尻尾を振るときは避けてください。

水のほこら

出発する前にマジックハンマー · 水かき · マジカルミラー

報酬フックショットと第2クリスタル

  1. 光の世界の北東にあるゾーラの領域で、水かきを500ルピーで購入します。彼らは宮殿を横切ることを可能にします。

  2. 闇の世界の南の遺跡へ行きます。 マジカルミラーを使用して、対応する光の世界の建物に入り、右のレバーを引きます。

  3. 終了してミラーポータルに戻ります。暗い宮殿に入り、水を渡り、敵を排除して最初の鍵を明らかにします。

  4. 下に降りて頭蓋骨の下にある鍵を探し、バルブを作動させます。 マジックハンマーを使用すると、障害物を下げることができます。

  5. 中央のプールから北西に開き、バルブを左に押します。クリスタルを設置してオレンジ色のブロックを下げ、南西の水路に泳ぎ込みます。西側では、下のブロックを左に押し、次に中央のブロックを上に押します。上がってください。北東の穴に落ちて東の宝箱を開ける。

  6. フックショットに乗ります。ポットをアタッチメントポイントとして使用して、隙間を越えて遠くのプラットフォームに到達します。

  7. 大きな宝箱の東にある壺でフックショットを使用して鍵を入手し、北にある壺に引っ掛けます。施錠されたドアの向こうで、像と一緒にスイッチを押し続けます。東側の左側の出入り口をご利用ください。レバーまで降りて水を抜きます。滝まで戻り、右から2番目の滝を通ります。最後の扉の前にある頭蓋骨の下にある最後の鍵を回収します。

  8. フックショットを準備してボス部屋に入ります。戦闘後、レセプタクルとクリスタルを受け取ります。

  2. ガノンの動きが止まったら剣で攻撃しましょう。テレポート中にトライデントを追いかけるのではなく、トライデントを避けてください。

  3. 火の輪から離れてコウモリを避けてください。地面が消え始めたら、端から離れてください。

  4. 両方の松明に火をつけます。ガノンが見えている間に剣で彼を攻撃して気絶させ、すぐにシルバーアローを撃ちます。松明に再び点火し、彼が倒れるまで繰り返します。

  5. 彼が敗北した後、北の通路を進みます。クレジットを見てください。サイト追跡は、コレクションを完了するために引き続き利用できます。

01

パラパ パレス

0 / 3 ステップ+

最初の宮殿を越える道を照らします。

攻略ルートと謎解き

  1. 01

    ラウルでシールドを学び、パラパ宮殿に入る前に道で経験を積んでください。シールドはダメージを軽減しますが、他の呪文に必要な魔法を使用します。

  2. 02

    クリスタルを置く前に、宮殿の側枝を探索してキャンドルを探してください。キャンドルは、後で使用されるオーバーワールドの洞窟を照らします。

  3. 03

    ホースヘッドに対しては、ジャンプして鎧の上から頭を打ち、メイスが揺れるにつれて後退します。勝利後、像に進み、クリスタルを置きます。

02

街とデスマウンテン

0 / 3 ステップ+

ハンマーを回収します。

攻略ルートと謎解き

  1. 01

    盗まれたトロフィーをルトに返してジャンプを覚えてもらう。サリアで女性の鏡を見つけてライフにアクセスし、バグーの許可を使って川を渡ります。

  2. 02

    デス マウンテンでは、すべての分岐点をランダムに選択するのではなく、洞窟の入り口と出口を記録します。ハンマーまでの最後のストレッチの前に補充してください。

  3. 03

    ハンマーを使用してオーバーワールドの岩を破壊し、近くのマジック コンテナに到達します。御堂では薬のクエストでフェアリーを入手し、ジャンプを使って下突き先生のところへ行きます。

03

ミドロパレス

0 / 3 ステップ+

壊れやすい石を通過します。

攻略ルートと謎解き

  1. 01

    ハンマーを使って沼地の宮殿に行きます。シールドとライフに十分な魔法を携行し、下の枝にあるハンディグローブを確認してください。

  2. 02

    グローブを使用すると、剣で攻撃してダンジョンのブロックを破壊できます。別のスイッチを探して時間を無駄にすることなく、これを使って封鎖された廊下に戻ります。

  3. 03

    戦闘が進むにつれて、ヘルメットヘッドのヘルメットが外れ、発射物が発射されます。ジャンプして傷つきやすい頭を攻撃し、浮いているヘルメットから遠ざかります。

04

アイランド パレス

0 / 3 ステップ+

ハイラル東に到着。

攻略ルートと謎解き

  1. 01

    海岸から洞窟ルートを通って島に到着します。ボスに進む前に、宮殿内でいかだを探してください。

  2. 02

    正面から近づくと危険な敵には下突きを使用します。通路や隙間に飛行が必要な場合は、フェアリーのために魔法を節約してください。

  3. 03

    レボナックはまず馬に乗って攻撃する。下向きの攻撃を使用して彼の座を外し、シールドの周りで高攻撃と低攻撃を交互に繰り返して露出したアイアンナックルと戦います。

05

迷路宮殿

0 / 3 ステップ+

ブーツを入手し、反射魔法を習得する。

攻略ルートと謎解き

  1. 01

    ハイラル東部で、ナブールにいる女性を火事で助けます。ダルニアに到達し、迷路島から子供を救い出し、リフレクトに戻ります。隠し先生から上向き推進力も学びましょう。

  2. 02

    迷路宮殿でブーツを取り戻しましょう。これにより、すべての海タイルではなく、オーバーワールド上の指定された浅瀬の小道を横断できるようになります。

  3. 03

    キャロックは通常の剣攻撃では倒すことができません。 Reflect をキャストし、彼の発射物に向かい、盾を発射物に向けてしゃがみます。

06

オーシャンパレス

0 / 3 ステップ+

攻略ルートと謎解き

  1. 01

    ブーツを使って東の海を渡るルートを見つけてください。次のクリスタルを配置する前に、宮殿でフルートを探してください。

  2. 02

    ライフやマジックが少ない場合は、オプションの経験バッグをすべて追いかけないでください。ボスの間は防御と回復のために十分な魔法を温存してください。

  3. 03

    ゴマは攻撃の合間に体を露出させたまま重火器を振り回す。剣を打ち込むために踏み込み、振りが届く前に後退します。

07

隠された宮殿

0 / 3 ステップ+

6番目のクリスタルを置きます。

攻略ルートと謎解き

  1. 01

    フルートを吹いてリバーデビルを排除します。 New Kasuto では、最後の魔法のコンテナと魔法を入手し、街の空き地で魔法を使用して魔法の鍵を表示します。

  2. 02

    三つの岩で笛を吹くと、隠された宮殿が現れます。十字架を回収し、目に見えない床の隙間に注意してください。意図的な転倒が新たなルートにつながることもあります。

  3. 03

    降下中はジャンプとフェアリーの魔法を温存しておきます。バルバに対しては、溶岩から出てくるドラゴンの頭をジャンプして攻撃し、安全な場所に戻ります。

08

大宮殿

0 / 3 ステップ+

勇気のトライフォースを手に入れましょう。

攻略ルートと謎解き

  1. 01

    6 つのクリスタルがすべて配置されていることを確認し、すべてのマジック コンテナを収集します。 Old Kasuto で Thunder を学び、Great Palace への長い道のりの前にエネルギーを補給してください。

  2. 02

    宮殿は戦闘テストであると同時にナビゲーションの挑戦でもあります。エレベーターの分岐にマークを付けて、最後の部屋の前で魔法を使い果たさないようにしましょう。

  3. 03

    サンダーをキャストしてサンダーバードの弱点を露出し、ジャンプして顔面を攻撃します。ダークリンクはすぐに続きます。ブロックし、攻撃の高さを変更し、絶えずジャンプする代わりに制御された隙を取ります。

心も魔法も技も

  1. 01
